# D 路线候选账本

## U01

| 候选 | 保留判断 | 淘汰或入选理由 |
|---|---|---|
| 艾丽斯·玛丽恩·杨：社会连接责任模型 | 最终选择 | 直接重构“复杂结构中个人是否有罪”的问题，把向后归责与面向未来的共享政治责任区分开；连接自然，且提供原文之外的稳定分析框架。 |
| Robin Zheng：角色理想模型 | 淘汰 | 能补足“具体个人该做什么”，但若作为主对象需要较多规范伦理前置；相对 Young，认知回报较窄，且容易转为同域争论。 |
| 可识别受害者效应 | 淘汰（R2） | 原文已直接写出单个儿童故事比统计数字更能促成捐款；换上术语后主要认知仍来自原文。 |
| 供应链尽职调查 | 淘汰（R3） | 是相关治理实践，但更像把原文推进到专业合规细节，未优先提供新的责任理解方式。 |

最终：社会连接责任模型。

## U02

| 候选 | 保留判断 | 淘汰或入选理由 |
|---|---|---|
| 海伦·尼森鲍姆：情境完整性 | 最终选择 | 把“谁拥有数据”重构为“具体信息流在特定情境下是否合宜”，提供角色、信息类型与传递原则等可迁移观察单元。 |
| 数据公地 | 淘汰（R5） | “共同拥有”与原文末尾有表面连接，但若不展开治理制度，容易只共享“公共资源”这一宽泛比喻。 |
| 财产权的权利束 | 淘汰（R3） | 能说明所有权并非单一权利，但仍围绕财产法内部细分；对数据流为何越界的解释力不及情境完整性。 |
| 监视资本主义 | 淘汰（R2/R3） | 容易把原文关于平台收集数据、操纵选择的论述换成更专业的同域名称，新增机制有限。 |

最终：情境完整性。

## U03

| 候选 | 保留判断 | 淘汰或入选理由 |
|---|---|---|
| 罗伯特·贝拉：公民宗教 | 最终选择 | 揭示现代国家不只借用传统宗教，也会以建国叙事、公共文献和仪式生产自己的神圣秩序；同时保留“更高标准可批判国家”的边界。 |
| 本尼迪克特·安德森：想象的共同体 | 淘汰（R2） | 原文已经明确以共同故事和群体认同解释大规模合作；删除术语后核心观察大半仍在原文。 |
| 涂尔干：集体欢腾 | 淘汰（R3） | 能细化仪式如何强化群体情感，但容易落入宗教社会学的同域专业扩展，问题重构不如公民宗教。 |
| 日常民族主义 | 淘汰（R3/R4） | 对日常符号维持国家认同有解释力，但与本章宗教仪式的连接需要额外补桥，且容易变成一般民族主义补充。 |

最终：公民宗教。
