# ABC 桥梁与候选台账

## U01

### A：值得重新观察的关系

1. 道德直觉能处理近距离、少人数且因果清晰的伤害；规模扩大与因果分化会让同一套判断失灵。
2. 个人可以没有直接恶意，却通过投资、消费或行政角色参与一条造成伤害的长链。
3. 获取事实的成本被不均匀分配：维持无知容易，认真追查则耗费巨大。
4. 面对不可理解的规模，人会用单一人物、感人个案、阴谋或教条替代复杂关系。

### B：关系桥梁

- A1
  - B-core：当结果由大量局部行动共同生成时，扩大参与者数量会改变归因结构，而不只是放大原有问题。
  - B-core：一套为短链条建立的判断规则，在长链条中会因控制权与信息分散而失去落点。
- A2
  - B-core（入选）：许多人的微小贡献共同造成伤害时，没有人控制全局，个人责任与集体责任之间会出现空缺。
  - B-core：角色分工能让每个参与者局部合规，同时让整体持续产生无人愿意承担的结果。
- A3
  - B-core（入选）：若发现后果所需的信息分散在不同节点，要求每个人自行查清全链条，会把制度缺陷转化成个人认知负担。
  - B-hypothesis：信息不透明可能被有权者有意维持；原文没有逐例证明“有意”，故未混入核心桥梁。
- A4
  - B-core：当整体无法直接表征时，人会用情绪上可处理的代理对象替代结构，从而获得确定感。

### C 候选（保留 3/4）

1. **多手问题（选用）**：多主体分工使因果、控制与选择分散，产生责任缺口；Thompson 保留基于因果与意志标准的个人责任，后续研究扩展到系统性伤害。通过 R1—R8；连接 A2/A3，自然且有机制增量。
2. **系统性伤害中的个人—集体双层责任（保留未选）**：Hormio 强调个人作为组织与群体成员的责任，不能只在个体／国家二选一。与候选 1 高度相邻，单独使用容易重复，故并入边界而不作为主 C。
3. **供应链可追溯性（淘汰）**：能回应信息分散，但容易滑向技术方案和同域细节，且无法独立回答责任分配，触发 R3／认知回报不足。

### 最终判定

选择“多手问题”。它把“世界太复杂”改写为可区分的因果、控制、角色与责任层级，而不是专业化复述原文。

## U02

### A：值得重新观察的关系

1. 重要生产资产从土地、机器转向数据时，权力集中可能先表现为控制流动和决策，而非占有有形物。
2. 数据巨头以免费服务换取注意力和信息，短期交易隐藏了长期控制价值。
3. 当健康、就业等必需服务依赖联网，形式上的“自愿退出”可能失去实际可行性。
4. 数据可复制、可高速移动且由多方共同生成，使土地式所有权语言难以直接适用。

### B：关系桥梁

- A1
  - B-core：当关键资源的价值来自持续访问和组合，而非一次占有时，实际控制接口者可能比名义所有者更有权力。
  - B-core：生产资源的集中可以通过设定访问规则实现，不必表现为法律上的完整所有权。
- A2
  - B-core：一方用即时、可见的小利益换取另一方难以估价的长期选择权，会形成跨时间的信息与议价不对称。
- A3
  - B-core：当退出会同时失去基本服务，同意仍存在于形式上，却不再等于有意义的选择。
- A4
  - B-core（入选）：若资源可被多人同时使用且由多方共同生成，“归谁”应拆成访问、使用、排除、转交与收益等不同权能。
  - B-core（入选）：技术架构可以先于法律分配事实控制，使没有产权名义的一方仍能排除他人并取得价值。

### 查询记录（6/10）

前三条没有使用原文直接领域词，并分别从非耗竭资源、生物样本、基础设施治理表达：

2. `genetic tissue samples bundle of rights governance beyond ownership`
3. `infrastructure access power asymmetry stewardship fiduciary governance resource`
4. `data governance bundle of rights access use exclude delete benefit official report`
5. `personal data ownership bundle of rights legal scholarship data non rival governance`
6. `data trusts fiduciary stewardship governance original report ODI`

打开页面：6/15（其中 2 页返回访问限制，仍按打开尝试如实计数）。核验来源：6 个（SSRN 论文摘要、PMC 基因组联盟论文摘要、ODI、Cardozo Law Review、Springer、Australian Law Reform Commission）。

### C 候选（保留 4/4）

1. **数据权利束（选用）**：把所有权拆为控制、访问、使用、分享与取值等可分别配置的权利，并揭示事实控制可替代法律产权。通过 R1—R8；直接承重 A4。
2. **数据托管／受托治理（保留未选）**：以独立受托者替一群利益相关者管理用途与访问。是真实制度，但仍属新兴且并非通用解，作为延伸入口而非主 C。
3. **个人数据所有权的自我挫败风险（保留未选）**：Cofone 指出单靠产权和同意会放大不对称、遗漏推断数据并产生道德风险。重要但理解成本更高，纳入主 C 边界。
4. **生物样本的有限权利／保管关系（保留未选）**：ALRC 展示占有、转让、收益等权利可被拆开。是良好类比证据，但不是最直接对象。

### 最终判定

选择“数据权利束”。它不是把数据换个名称，而是把一个单选政治问题改造成可逐项审计的权能配置问题。

## U03

### A：值得重新观察的关系

1. 一套传统在技术与政策问题上失去知识权威后，仍可在身份划界上保有强大作用。
2. 解释技能让古老文本能够为相反的现代政策提供权威包装，答案的来源与正当化语言由此分离。
3. 日常仪式以重复、服饰、禁忌和共同情绪把流动的人群边界变得可感。
4. 现代国家可以重组地方传统与新观念，以古老连续性的外观支撑现代组织和牺牲。

### B：关系桥梁

- A1
  - B-core：一种制度即使不再提供有效答案，仍能凭划分成员身份来决定合作与资源指向。
- A2
  - B-core：当结论先由外部知识与利益形成，经典解释可以从发现答案的工具变成追认答案的权威语言。
- A3
  - B-core（入选）：重复的共同动作会把抽象成员资格转化为亲近感、同步情绪和可见承诺，从而改变行动成本。
  - B-core：外人看来微小的标记，对成员而言可成为判断可信、亲近与忠诚的高密度信号。
- A4
  - B-core（入选）：新制度借用旧符号制造历史连续感，能让快速变化的秩序显得自然，并把个人使命嵌入集体叙事。
  - B-hypothesis：所有此类重组都是精英有意操纵；原文不足以支持“所有”与“有意”，故不列为核心。

### 查询记录（6/10）

前三条没有使用原文直接领域词，并分别从组织仪式、国家传统、制度性解释表达：

1. `organizational ceremonies mark insiders outsiders costly signals group identity research`
2. `invented tradition modern state loyalty rituals historical concept`
3. `after decision reinterpret canonical text support policy motivated reasoning institutions`
4. `credibility enhancing displays CREDs rituals costly behavior belief transmission original paper Henrich`
5. `identity fusion visceral feeling oneness group extreme self sacrifice original research`
6. `Eric Hobsbawm invented traditions continuity past repetition functions primary excerpt Cambridge`

打开页面：9/15（其中 4 页返回访问限制，仍按打开尝试如实计数）。核验来源：6 个（APS、Oxford Research Archive 摘要、Wiley 摘要、Springer、Cambridge、Max Planck 托管论文）。

### C 候选（保留 4/4）

1. **身份融合（选用）**：个人自我不消失，而与群体自我协同；能动感、家人般关系与共享本质感关联高代价的群体行动。通过 R1—R8；为 A3/A4 提供原文之外的机制与重要区分。
2. **发明的传统（淘汰）**：Hobsbawm 说明近期创设的仪式可声称连接古老过去。真实且自然，但原文已经完整写出国家重造神道，删除名称后增量有限，触发 R2。
3. **可信度增强展示（保留未选）**：高成本行为使相配套的信念对观察者更可信，并经社会学习传播。机制扎实，但与原文的主要锚点连接需要更多中间论证，优先级低于身份融合。
4. **仪式中的情绪同步（保留未选）**：纵向研究观察到集体仪式参与后身份融合上升，情绪同步可能中介。证据尚新且场景有限，用作边界证据，不独立选用。

### 最终判定

选择“身份融合”。它纠正“集体忠诚必然抹掉个人”的直觉，解释现代个人能动性为何可能反而加强高代价的集体行动，同时保留效应大小与因果外推的限制。
