# 会话 4：技术审核、匿名装配与盲审材料生成

## 输入

- `pilot-inputs/`
- `direct-output/`
- `abc-output/`
- 本任务文件
- `05_PRODUCT_RULES.md`
- `06_OUTPUT_FORMAT.md`
- `07_AUDIT_RUBRIC.md`

## 任务

### 1. 核验运行公平性

检查：

- 模型是否相同；
- 思考强度是否相同；
- 搜索预算是否一致；
- 是否存在跨路线污染；
- 是否读取历史答案；
- 是否出现提示词修改或补跑。

严重不公平时标记 `EXPERIMENT_INVALID`，但保留全部产物。

### 2. 技术审核

对 6 条成品分别检查：

- 来源是否真实；
- C 是否稳定存在；
- 是否歪曲 C；
- 是否违反八类反例边界；
- 是否违反认知回报线；
- 是否现场编造 M2/M3；
- 是否达到最小人类可读完整度。

只标记，不重写成品。

### 3. 匿名配对

对 U01、U02、U03：

- 随机决定左右顺序；
- 隐藏 D／ABC 路线；
- 隐藏模型、搜索记录、成本与评分；
- 保留完整原文上下文和两条成品；
- 若一方 `SILENCE`，显示“本路线选择沉默”，但不揭示路线。

### 4. 生成产品盲审文件

每组附：

```text
产品判断：
[ ] 左边更好
[ ] 右边更好
[ ] 两边都值得
[ ] 两边都不值得
[ ] 难以判断

左边是否提供原文之外的新观察：
[ ] 是
[ ] 否

右边是否提供原文之外的新观察：
[ ] 是
[ ] 否

哪一边连接更自然：
[ ] 左
[ ] 右
[ ] 相同
[ ] 都不自然

哪一边更愿意保留在书里：
[ ] 左
[ ] 右
[ ] 两边
[ ] 都不保留

一句理由：
```

不得在产品审阅前生成路线胜负结论。
