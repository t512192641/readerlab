# 近终稿陪读统一格式

每个主题单元最多输出 1 条陪读。正文建议 500—900 个汉字；来源与继续阅读另计。

若无合格候选，写：

```text
status: SILENCE
reason: <为什么沉默>
```

有产出时使用：

```markdown
status: PROPOSED

## 原文锚点

<引用必要但不过长的原文；必须来自输入>

## 陪读标题

<自然中文标题，不用“XX 理论告诉我们”式标题>

## 陪读正文

先让读者理解 C，再自然连接 A。

正文必须完成：

1. C 是什么；
2. C 原本解释什么；
3. 为什么在这里自然想到它；
4. 它让读者比原文多看到了什么；
5. 必要的边界。

不得把内部 A/B/C 字段直接写进正文。

## 继续了解

- 人物／理论／书籍：
- 代表来源：
- 适合继续阅读的入口：
- C 原本拥有的深度：M1 | M1+M2 | M1+M2+M3
- 若包含 ReaderLab 应用提示，明确标注其不是原作者正式方法。
```

正文不负责解释作者原文，不做小论文式完整综述，不强制给出操作步骤。
