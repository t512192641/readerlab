# 技术审核标准

每条成品逐项标记 PASS / FAIL / UNCERTAIN。

## H1 来源真实
对象与来源可核验。

## H2 表达准确
对 C 的核心机制没有明显歪曲。

## H3 连接自然
系统已经说明为什么 C 会在当前原文中出现，不需要读者代为补桥。

## H4 外部知识承重
删除 C 后，主要认知增量消失。

## H5 非同域专业扩展
不是只增加原文领域中的更细知识。

## H6 认知回报合格
理解成本与认知增量相称。

## H7 无表面跨域
至少存在一条具体关系、机制或重要区分，而非宽泛词相似。

## H8 无原创伪装
没有把 ReaderLab 新编内容冒充原作者框架。

## H9 人类可读
产品负责人无需先懂 C，也能判断价值。

## H10 篇幅与阅读位置合理
没有为了证明理论而写成过重的学术备忘录。

### 技术资格

- `TECH_PASS`：H1、H2、H3、H4、H8、H9 全部 PASS，且总 FAIL 不超过 1。
- `TECH_BORDERLINE`：关键项无 FAIL，但有多个 UNCERTAIN。
- `TECH_REJECT`：H1、H2、H3、H4 或 H8 任一 FAIL。

技术资格不替代产品判断。
