# ReaderLab 当前冻结的产品边界

## 最小正向定义

一条陪读中的外部对象 C 必须：

- 真实存在；
- 可追溯；
- 与原文有自然、可说明的连接；
- 引入后形成原文之外的新观察单元；
- 不依赖模型现场编造；
- 不只是专业化复述。

新观察单元可以是：

- 新概念；
- 重要区分；
- 解释机制；
- 新的问题定义；
- 稳定分析方法。

不强制必须达到方法论或 M3。

## 八类反例

### R1 术语贴标签
只有名字和定义，没有说明它改变了原文中的什么。

### R2 原文抽象改写
删除 C 名称后，核心认知仍完整来自原文。

### R3 同域专业扩展
只是把原文引向更专业、更细、更难的同领域知识，没有提供新的理解世界方式。

### R4 连接由读者补完
C 本身很好，但系统没有自然说明为什么应当在这里出现。

### R5 表面跨域
只共享“分类、边界、效率、复杂性、信息损失”等宽泛词，没有承重关系。

### R6 歪曲真实理论
陪读让读者带走的主要判断并非 C 所支持。

### R7 模型原创方法
为了完整，临时编造四步法、五问法或新框架，并冒充 C 的原生内容。

### R8 重复疲劳
同一实验或同一本书中，不应反复使用相同 C 或同一安全框架的同质应用。

## 三条新增约束

### 认知回报线

若理解 C 需要大量专业前置知识，而它只增加同领域细节，则淘汰。专业难度必须换回明显的问题重构、机制增量或可迁移观察。

### 重复疲劳线

本轮只做人工记录：同一 C 不得重复出现；高度相近的安全框架应降低优先级。

### 忠实展开线

允许恢复 C 原本拥有的 M1、M2、M3 深度；不得为了产品完整度替 C 发明不存在的机制或方法。
