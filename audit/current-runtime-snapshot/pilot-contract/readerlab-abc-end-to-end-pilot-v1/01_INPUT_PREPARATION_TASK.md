# 会话 1：准备冻结输入

## 任务

从 ReaderLab 历史证据包或仓库中的冻结测试输入中，定位并复制：

- F01
- F02
- F04

只复制原始测试文本，不得复制：

- answer-key；
- 历史候选；
- 历史 Reader；
- 产品判词；
- 来源审核；
- P2/P3 结论；
- 文件名中会泄露历史结果的信息。

## 输出

创建：

```text
pilot-inputs/
├── U01.md
├── U02.md
├── U03.md
└── input-manifest.md
```

映射：

- F01 → U01
- F02 → U02
- F04 → U03

每份 U 文件必须保留：

- 原文标题（若冻结输入中存在）；
- 章节或主题单元位置；
- 完整冻结原文；
- 原有段落顺序。

不得摘要、改写或删减。

`input-manifest.md` 记录：

- 原始文件路径；
- 新文件路径；
- 字节数；
- SHA-256；
- 明确声明没有复制答案、历史结果和判词。

完成后压缩 `pilot-inputs/` 并停止。
