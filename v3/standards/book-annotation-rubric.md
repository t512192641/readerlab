# 图书线绝对裁判标准

状态：Phase 1 已收档；本文件只定义候选与读者成品的四道绝对门。生产顺序见 `v3/skill/protocols/book-engine.md`，历史病例只按 `v3/standards/regression-suite.md` 的 B-* case 读取。

## 判定方式

- 逐条判定，不做相对排名、平均分或多数表决。
- 四门全部通过才可进入观点锁定；任一门失败即淘汰或退回对应上游。
- 通过数量允许为 0。结构齐全、表达漂亮、已经花费生产成本或是“本批最好”都不能降门槛。
- 候选只证明一项认知任务；局部通过不得升级为整章、图书线或完整流水线通过。

## 门一：完整认知

候选必须作为一个整体同时交付：

1. 一个清楚且可争辩的判断；
2. 它纠正或深化的默认理解；
3. 支撑判断的少量必要证据；
4. 它怎样具体改变附近原文的读法；
5. 必要边界和不应扩张之处。

只有事实、人名、书名、案例、模型、类比、素材清单或对原文的高级换皮，一律不算完整认知。候选若需要读者自己从新增材料里再找重点，也不通过。

## 门二：单一认知任务

一个候选只能改变一种原文读法。标题、判断、证据和收束必须回答同一个问题；多个事实只能共同承重，不能各自开启新主题。

若删掉任一支线后主判断仍完整，该支线就是加料，应删除。若候选实际上在讲两件事，必须拆开并分别重新接受完整裁判，不得以篇幅顺滑为由合并。

## 门三：证据

- 原文锚点可由 source map 精确定位，正文没有被 AI 转述替代。
- 外部事实、引文和因果断言在本次运行有可定位的高可信来源；旧链接只可作线索。
- 证据确实支持判断及其强度，类比说明相似处、差异和适用边界。
- 事实不确定、来源无法复核、模型名代替机制或案例只是在解释另一个案例，均不通过。

证据充分不等于值得呈现；仍须通过完整认知、单一任务与冷读门。

## 门四：冷读

无生产上下文的冷读者必须能够：

1. 一句话复述这条内容的唯一判断；
2. 指出自己新增知道了什么；
3. 说明它怎样改变了附近原文的读法；
4. 直接读懂，不需重排素材、解释生产词或猜测落点。

表达应像懂行的人自然说明事实与判断。若内容只是复述、讲座式发散、漂亮姿态、术语清单、模板外露，或比原文更难懂，冷读失败。成文修订不得改变已锁定判断、增加事实或展开新问题。

## 历史防回归

- 正例边界：`B-P01`—`B-P03` 必须保持原证明范围，不重新校准，也不升级承诺。
- 硬负例：`B-N01`—`B-N09` 必须继续淘汰。
- 具体原文、判词与证据位置均由 `v3/standards/regression-suite.md` 路由；本文件不复制病例清单，不让生产角色读取回归答案。
