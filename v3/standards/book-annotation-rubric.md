# 图书批注评分标准

修订状态：R6 第二次架构修订。R4 证明单靠规则清单仍会让模型写出“看起来合规但不够有用”的批注；R5 证明三段式生产能降低机械错误，但仍会放出 60 分批注。R6 起，生成与裁判以 `v3/skill/protocols/book-engine.md` 的死刑制为准。本文件保留失败类型、历史术语、读者判定口径和产品铁律，不再作为候选的绝对打分裁判。

本标准评价正文旁批注，不评价摘要。合格批注必须从原文锚点出发，带读者到正文外看见真实的人、书、案例、概念或方法，再落回原文。

产品铁律：可见即精选。低于 `有用` 的批注不得出现在读者页；宁交活点清单，不交平庸批注。活点清单包括锚点、为什么值得批、素材线索，不冒充批注。

历史评分：1 分为废弃，2 分为平庸，3 分为可用，4 分为有用，5 分为惊艳。R6 以后不再用绝对打分决定上页，改为死刑制：候选必须在与金标成对比较中不输，才允许上页。

惊艳定义：教会读者一个凭原文无法自行获得的东西。若读者盯着原文想两分钟就能自己得出，最高只能评 3 分。已经在校准中反复曝光过的内容，即使形态正确，也不再计惊艳。

长度目标：每条批注 80-150 字，一体成文。R3 的“页边批注 + 延伸块”两段式结构废止。

R6 裁判口径：`有用` 地板来自四件事：素材卡有事实、每锚点有非第一联想素材、成文不输金标、自检无即死项。`惊艳` 只作为用户判定结果记录，不作为 Skill 保证。若无候选存活，交付活点清单，不交付批注。

## 五条形态铁律

1. 环线结构：从锚点出发，场外走一趟，必须落回原文。只飞出去不回来，是讲座；只待在原文里，是复述。
2. 场外实货：批注必须带真实案例、人名、书名或概念名，并随讲随用人话解释。模型名不能当结论。
3. 每句携带带走物：优先保留能让人顺着找到人、书、案例、概念或方法的句子；空泛判断和漂亮姿态删掉。
4. 说话不写作：朗读测试要像懂行的朋友随口讲。禁止开场铺垫、对仗修辞、格言式收尾和转身面向读者的说教。
5. 解释性推理能删则删：读者自己能推出的道理就是填充物。机制解释最多一个短句，篇幅留给场外实货和落回原文。

## 维度一：锚点与环线

| 分数 | 判定 |
| --- | --- |
| 1 | 没有指向具体原文，只是读后感。 |
| 2 | 指到章节主题，但不能定位到具体句子、案例或转折。 |
| 3 | 能贴住具体段落，但批注基本停留在场内展开。 |
| 4 | 从具体锚点出发，引入场外材料后自然落回原文。 |
| 5 | 锚点、场外材料和落点形成闭环，删掉会损失本段理解枢纽。 |

低分例：这一段说明组织沟通很重要，大家要打破部门墙。

## 维度二：场外增量

| 分数 | 判定 |
| --- | --- |
| 1 | 复述原文。 |
| 2 | 用高级词重说原文。 |
| 3 | 把原文暗含的机制、边界或推论说破，但读者盯着原文两分钟基本能得出。 |
| 4 | 带来真实案例、人名、书名、概念名、方法论体系、具体反例或跨书连接，并用人话解释其用法。 |
| 5 | 场外增量改变读者看待本段或本章的方式，并提供一个凭原文无法自行获得的学习出口。 |

自检问句：读者盯着原文想两分钟能自己得出吗？能，则增量性最高 3 分。

## 维度三：承重性

| 分数 | 判定 |
| --- | --- |
| 1 | 删掉完全不影响阅读。 |
| 2 | 有一点提醒，但正文已经说清。 |
| 3 | 能减少一个小误读。 |
| 4 | 删掉会损失关键边界、案例、反例或外部连接。 |
| 5 | 删掉会让读者把本段读浅、读偏，或错过真正可学的出口。 |

高分例：针对“电池组团队做了封装，车身团队又要求封闭结构，于是出现外壳套外壳”，批注说：这里可接康威定律，但别只背名字。Mel Conway 讲的是组织沟通结构会长到系统里；落回这段，两个团队各自做对，合起来却把部门边界铸成了车身重量。

## 维度四：经验分量

| 分数 | 判定 |
| --- | --- |
| 1 | 像通用鸡汤。 |
| 2 | 像咨询术语，没有真实代价。 |
| 3 | 有经验感，但太抽象。 |
| 4 | 能说出实际组织、产品、工程或个人行动中的代价。 |
| 5 | 像付过学费的人在旁边低声补一句，并给出可追索的人、书、案例或方法。 |

允许第一人称经验，例如“我见过”“我们当年栽在”“这让我想起”。第一人称必须交付实质知识，不能只展示姿态。

## 维度五：边界诚实

| 分数 | 判定 |
| --- | --- |
| 1 | 类比乱飞，不说明差异。 |
| 2 | 给出模型名，但不说适用条件。 |
| 3 | 有边界提示，但泛泛而谈。 |
| 4 | 明确说明场外材料和原文相似在哪里、不同在哪里。 |
| 5 | 同时说明相似点、不同点、迁移代价，并把边界落回原文。 |

低分例：这就是康威定律，所有组织结构都会反映在产品里。

## 维度六：语域与形态

| 分数 | 判定 |
| --- | --- |
| 1 | 转身面向读者说教，或出现“提醒读者”“你应该”“读到这里可以”等下指令句式。 |
| 2 | 语气平顺但像导读、讲义、总结或公众号金句。 |
| 3 | 页边口吻基本成立，但场外内容只是报菜名，或解释性推理过多。 |
| 4 | 像懂行朋友随口讲，场外实货随讲随解释，80-150 字内完成闭环。 |
| 5 | 口语、实货、落点和节奏同时成立，读完像旁边多坐了一个真正懂行的人。 |

## 用户确认形态正例

以下两条例子用于校准 R4 目标语域。用户已确认其形态；内容因重复曝光，不再作为后续惊艳判定依据。

正例一：这句别只读成“多读书多问人”。土星五号图纸还在，难的是焊接、容差、试车这些隐性知识断了；Harry Collins 说的 tacit knowledge，就是写不进手册的会。落回原文：书能开门，老手和现场才把手感补回来。

正例二：这句不是悲观，是 Gary Klein 的 pre-mortem：开工前先假设半年后失败，再倒推它怎么死。NASA 的 go/no-go 也干这事，把骄傲赶出房间。落回原文：胜券在握仍假设失败，是给自信装刹车。

## 即死清单

- 复述原文。
- 高级词换皮。
- 工整但全程场内展开。
- 模型名当结论。
- 报出人名、书名、框架、学科或概念名但不随讲随解释。
- 无锚点感想。
- 只飞出原文，不落回原文。
- 讲座式发散。
- 说教收尾，例如“提醒读者”“你应该”“读到这里可以”“最有价值的问题不是 X 而是 Y”。
- 开场铺垫、对仗修辞、格言式收尾。
- 解释性推理超标，把读者自己能推出的道理写满一段。
- 只夸作者聪明或风格强硬。
- 把极端组织条件直接移植成普遍人生建议。
- 事实不确定却用肯定语气。
- 批注比正文更难懂。

## R6 上页门槛

1. 每个锚点先生成 5-7 路候选，分别从不同学科或付过学费的身份出发。
2. 每个锚点的素材卡至少包含一件非第一联想素材，并写清 2-3 个确实知道的事实。
3. 候选先过即死清单；命中任一项，修复后仍命中则淘汰。
4. 候选再与金标正例成对比较。不能证明“不输金标”的，淘汰。
5. 存活 0 条时，读者页只交付活点清单；这不是失败，而是避免把平庸内容伪装成陪读。
