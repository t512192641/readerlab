# 图书批注评分标准

修订状态：R2 前第 1 轮修订。R1 暴露的问题是：裁判能识别明显廉价总结，但会把工整的场内展开误判成高价值。以下标准因此收紧“增量性”和“惊艳”。

本标准评价的是正文旁批注，不评价摘要。合格批注必须先贴住原文，再给读者带来原文没有直接说出的理解增量。

评分：1 分为废弃，2 分为平庸，3 分为可用，4 分为有用，5 分为惊艳。裁判默认淘汰 1-2 分，3 分只在覆盖关键锚点时保留，4-5 分进入候选成稿。

惊艳定义：教会读者一个凭原文无法自行获得的东西。若读者盯着原文想两分钟就能自己得出，最高只能评 3 分。

## 维度一：锚点性

| 分数 | 判定 |
| --- | --- |
| 1 | 没有指向具体原文，只是读后感。 |
| 2 | 指到章节主题，但不能定位到具体句子、案例或转折。 |
| 3 | 能定位到具体段落，但批注和锚点关系偏松。 |
| 4 | 明确贴住一句话、一个案例或一个推论转折。 |
| 5 | 不仅贴住锚点，还说明为什么这个锚点是本段理解枢纽。 |

高分例：针对“电池组团队做了封装，车身团队又要求封闭结构，于是出现外壳套外壳”，批注说：这里的关键不是“跨部门沟通要快”，而是组织边界会变成实体边界；两个团队各自合理，合在一起就把成本和重量固化进产品。

低分例：这一段说明组织沟通很重要，大家要打破部门墙。

## 维度二：增量性

| 分数 | 判定 |
| --- | --- |
| 1 | 复述原文。 |
| 2 | 用高级词重说原文。 |
| 3 | 把原文暗含的机制、边界或推论替读者说破，但仍停留在场内展开。 |
| 4 | 在贴住原文的基础上，至少提供一种场外增量：真实案例、思想谱系、有名字的学科 / 方法论体系、具体反例、与本书其他章或其他书的对账连接。 |
| 5 | 场外增量改变读者看待本段或本章的方式，并教会读者一个凭原文无法自行获得的东西。 |

场内展开说明：凡只是把原文暗含的机制、边界、代价、误读风险替读者说破，即使写得工整，也封顶 3 分。4-5 分必须越出本段文本，带来读者无法靠盯着原文两分钟自行获得的外部连接。

自检问句：读者盯着原文想两分钟能自己得出吗？能，则增量性最高 3 分。

高分例：针对“沟通应沿最短路径实现目标”，批注说：这不是反管理，而是在高耦合工程里临时把组织图让位给问题图；风险是绕过责任制，所以原文同时要求“以公司全局利益”和“主动担责”。

低分例：这句话体现第一性原理，因为马斯克喜欢直接解决本质问题。

## 维度三：承重性

| 分数 | 判定 |
| --- | --- |
| 1 | 删掉完全不影响阅读。 |
| 2 | 有一点提醒，但正文已经说清。 |
| 3 | 能减少一个小误读。 |
| 4 | 删掉会损失关键边界、机制或反例。 |
| 5 | 删掉会让读者把本章读成相反方向。 |

高分例：针对“强推指挥链的管理者终将被淘汰”，批注说：不能把这句移植成“所有公司都该越级沟通”。它的承重条件是问题跨越多个专业边界且传递损耗大；在安全、合规或人事场景，最短路径可能反而制造事故。

低分例：这里说明马斯克很强硬，读者要注意他的管理风格。

## 维度四：经验分量

| 分数 | 判定 |
| --- | --- |
| 1 | 像通用鸡汤。 |
| 2 | 像咨询术语，没有真实代价。 |
| 3 | 有经验感，但太抽象。 |
| 4 | 能说出实际组织、产品或个人行动中的代价。 |
| 5 | 像付过学费的人在提醒读者哪里会出错。 |

高分例：针对“装配线工人应能立即找到设计师质问”，批注说：这条在真实公司最难的不是开沟通渠道，而是保护提问者不被中层秋后算账；没有这个保护，所谓一线反馈会变成又一个表格流程。

低分例：一线员工最了解真实问题，所以公司应该多听一线声音。

## 维度五：边界诚实

| 分数 | 判定 |
| --- | --- |
| 1 | 类比乱飞，不说明差异。 |
| 2 | 给出模型名，但不说适用条件。 |
| 3 | 有边界提示，但泛泛而谈。 |
| 4 | 明确说明什么情况下不成立。 |
| 5 | 同时说明相似点、不同点和迁移代价。 |

高分例：把“外壳套外壳”类比到软件团队时，批注必须说明相似点是团队边界沉积成系统边界；不同点是软件冗余有时是可靠性隔离，不一定像硬件外壳那样只增加重量。

低分例：这就是康威定律，所有组织结构都会反映在产品里。

## 即死清单

- 复述原文。
- 高级词换皮。
- 模型名当结论。
- 无锚点感想。
- 讲座式发散。
- 只夸作者聪明或风格强硬。
- 把极端组织条件直接移植成普遍人生建议。
- 事实不确定却用肯定语气。
- 批注比正文更难懂。
- 没有说明读者为什么需要这条批注。
