# 资产卡冷启动验收标准

## 测试协议

1. 开一个无上下文新 Agent。
2. 只给资产卡本体，不给原 Skill、原文、项目背景、历史解释或文件路径。
3. 明确禁止读取本地文件、搜索网页或请求额外上下文。
4. 要求 Agent 逐卡回答：问题、做法、边界、第一步。
5. 要求 Agent 对每张卡演练三个场景：明确适用、明确不适用、边界场景。

## 通过标准

全部满足才算通过：

1. 四要素复述完整：问题 / 做法 / 边界 / 第一步。
2. 三场景演练完整：一个明确适用、一个明确不适用、一个边界场景。前两个判断必须正确，边界场景必须说出关键考量。
3. 无悬空引用：卡内不得出现未解释的项目内部术语、路径、阶段号、缩写或只在原文里才成立的说法。
4. 测试发现缺口后，必须先修订卡片，再重测。

## 不通过条件

- “通过但带改进项”不算通过。
- Agent 只能复述卡片标题，不能说清边界或第一步。
- Agent 的适用 / 不适用判断明显错。
- Agent 需要原 Skill 或项目背景才能理解卡片。
- 卡片里出现未解释的内部路径、阶段号、工具名或缩写。
