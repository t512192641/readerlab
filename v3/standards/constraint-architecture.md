# ReaderLab V3 约束架构

状态：V3 约束唯一总则。运行方式见 `v3/skill/templates/run-manifest.md`；历史判定见 `v3/standards/regression-suite.md`。

## 适用与冲突

- 本文件供主控、架构审查和冲突裁决读取；执行角色只读主控提供的线路规则摘录、自己的短合同和任务输入。
- 冲突优先级固定为：来源真实 > 真正有价值 > 读者能理解 > 表达漂亮 > 格式完整。
- 当前规则只能归入一种主责：生产条件、表达要求、淘汰信号或验收承诺。其他文件引用，不复制长段。

## 五条总原则

### 原则一：一手主体不可被 AI 替代

- 图书与长文保留完整正文，只做轻量清理和剥离已确认的旧 AI 块。
- Skill 与工程材料提供可追溯的净化正文；用途、触发、判断顺序、流程、约束、失败和输出必须能回到源证据。
- AI 的概括、解释、评价、建议与外部联想进入独立槽位，不得冒充正文。

### 原则二：内部广泛搜索，外部极少呈现

- 只在搜索不确定性高、并行收益明显的环节使用集群；正文整理、最终成文和冷读不做投票扩容。
- 多视角是盲区审计，不是可见内容配额；读者页只出现胜出的完整认知或关键机制。
- 没有胜出者时 0 条合法。

### 原则三：一个可见单元只完成一个认知任务

- 图书单元只改变一种原文读法；Skill 单元只讲清一个机制、关键取舍或失败边界。
- 多个事实只能共同支撑同一个判断；读者不负责从新增材料中再次找重点。

### 原则四：证据层与读者表达分开

- 来源、source map、事实核查、候选、裁判、评分、运行和淘汰证据留在 audit / contracts / eval。
- 读者页只保留一手主体和自然中文表达，不出现生产词、运行结构或用术语代替的解释。
- 每个外部事实在 audit 中有可定位来源。

### 原则五：任何承诺都必须经过对应的独立验收

- 认知增量由无上下文冷读者说明“多知道了什么、怎样改变原文读法”。
- 好读由冷读者一句话复述，并确认不需二次整理。
- 事实可靠由可见判断到原始或高可信来源的追踪证明。
- 一手主体由 source map 逐段说明保留、移动和删除证明。
- Skill 可复用由无上下文冷启动或复现证明；完整流程真实跑通另过运行完整性门。
- 相对排名、机械格式和“候选中最好”不能替代任何绝对验收。

## 图书线两条专属规则

### 图书规则 A：候选必须是完整认知，不是素材

候选须同时给出唯一判断、要纠正或深化的默认理解、少量必要证据、对原文读法的具体改变和必要边界。事实、人名、书名、案例、模型和素材卡都只是证据，不能单独参赛；多条知识先合成一个同题判断，再作为完整候选受审。

### 图书规则 B：表达者不得重新选题或加料

成文者只接收锁定判断、必要证据、原文落点、边界和禁止枝节；只负责说清楚，不得改题、加新事实、拼装落选材料、展开第二问题或补成小论文。长度服从认知任务，说完即止。

## Skill / 工程线两条专属规则

### Skill 规则 A：净化正文只能做可追溯整理

允许删除、分组和轻量断句，不允许把源材料改写成 AI 总结。每个保留单元定位到源 Skill、脚本、模板、架构或数据流证据；重要删除类型记录理由。解释、评价、概括、方法论命名、建议和外部比较进入独立解读页。

### Skill 规则 B：技术解读必须讲机制、取舍和失败

按材料适用性检查输入到输出、状态/分支/权限/人工门、关键设计的反事实、失败/恢复/停止、验证与迁移边界。方法论指认、时代评审和外部知识只有在源证据成立或用户明确要求时启动，不设可见配额。

## 四层分发

1. 项目宪法：本文件，仅主控、架构审查和冲突裁决完整读取。
2. 线路协议：只由主控 / 线路编排读取 `book-engine.md` 或 `skill-engine.md`，再向执行者分发本线路两条专属规则的任务摘录。
3. 角色合同：执行者只读主控提供的线路规则摘录、`v3/skill/roles/` 下自己的文件和任务输入；每份行为规则不超过 7 条。
4. 回归样本：仅裁判与回归执行者按 `regression-suite.md` 的 case 路由读取。

## 规则归属

| 类型 | 主责内容 | 主文件 |
| --- | --- | --- |
| 生产条件 | 原始来源、运行模式、允许输入、source map、角色分工与预算 | `SKILL.md`、两线协议、run manifest |

## 选择性集群与预算

- 标准图书章的无早停计划为 11 个任务：正文/来源地图 1，锚点提名 2 + 归并 1，认知候选 3，事实核查 1，裁判 1，成文 1，冷读 1。合法 0 候选会把无输入的下游 dispatch 记为 skipped，`actual_tasks` 只计实际执行，不能为凑 11 伪造空任务。短文 5—7；深读档 15—18。
- 图书无早停标准链为 11 个任务；盲区检查由认知裁判在同一任务内完成。扩容只因高价值锚点首轮皆普通、事实冲突改变结论、裁判发现关键遗漏或用户明确要求；未经用户同意不得突破声明上限。
- Skill 标准链为 5 个任务：来源整合、机制候选、独立裁判、单一成文、独立冷读/冷启动/复现。简单材料可合并为 3—4 个任务，但生产者不得自评通过；复杂源码包只有在不重叠模块确需分片时才申请扩容，不做图书式专家竞赛。
- `SKILL.md` 不超过 300 行；单个线路协议目标不超过约两页。超限时拆角色合同，不继续堆禁令。
