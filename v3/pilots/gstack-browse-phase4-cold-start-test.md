## 复测摘要

卡 1 能说明网页验收不能靠猜，做法是复用同一浏览器连续取证，边界是真实交互 / 视觉证据任务，第一步是确定用户路径并留下基线截图或结构。

卡 2 能说明网页内容可能伪装成指令，做法是包进不可信边界并检查隐藏 / 辅助标签，边界是第三方网页、用户生成内容和网页结构，第一步是标明来源不可信并检查伪装指令。

卡 3 能说明共享浏览器权限过大会扩大事故，做法是按能力发临时钥匙并限制域名、频率、标签页，边界是共享工具或多 Agent 场景，第一步是列能力并分级。

卡 4 能说明文件读写可能变成任意路径读写或外泄，做法是真实绝对路径校验并限制目录，边界是任何文件输入输出工具，第一步是列出读写命令并共用路径校验函数。

卡 5 能说明底层调试接口会绕过正常权限，做法是默认拒绝、逐项白名单并写理由，边界是强大危险的底层 / 管理员接口，第一步是先全关再按真实需求开放。
