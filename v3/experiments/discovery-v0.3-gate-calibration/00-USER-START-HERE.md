# 匿名产品卡校准

这份材料用于判断六张匿名产品卡是否能为 ReaderLab 用户带来清楚、诚实、可行动的阅读价值。请只评价卡片作为产品内容的帮助程度与证据边界，不猜测卡片来源，也不要尝试恢复身份或分类。

请先阅读 `04-anonymous-product-cards.md`，再填写 `05-user-verdict-form.md`。完成自己的判断以前，不要打开 `06-agent-hidden-verdicts.md`，也不要查看映射文件。先独立判断，再揭盲，才能保留这次校准的意义。

本轮只判产品价值：这些卡片是否让读者多做了一个有用判断？是否清楚区分了材料中已经出现的内容与卡片提出的条件性分析？哪些卡片值得继续打磨，哪些卡片不适合进入产品？不要填写或推测任何身份分类。
