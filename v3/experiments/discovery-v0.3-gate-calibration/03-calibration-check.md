# ReaderLab v0.3 Gate 校准检查

## 0. 检查对象

本文件逐项检查六个锚点是否与 `01-gate-v0.3.md` 的门槛一致：

1. Gate 1：原生问题匹配；
2. Gate 2：独立分析语法；
3. Gate 3：作者等价测试；
4. Gate 4：L1／L2／L3 主张强度；
5. Gate 5：产品新增结果；
6. 四类结果映射：CORE／DEEPENING／HOLD／REJECT。

检查结论：六个锚点彼此一致。v0.3 的关键校准不是降低证据要求，而是把“L2 的受限机制主张”与“L3 的个案已证”分开，并把作者等价测试放在 CORE 之前。

## 1. 锚点一：Gate 1 原生问题匹配

### 一致性检查

- C1、C2、C3、C4、C5、C6、C8、C9 都能在章节的技术／政策／身份问题中找到直接或部分原生入口；它们的 HOLD 或 DEEPENING 不是因为主题不相干。
- K1、K2、K3、K4、K6、K7、K9、K10 都能从章节的身份、国家神道、仪式、忠诚或全球／地方冲突找到原生入口，但入口是否足以承载完整机制由 Gate 4 再判断。
- K8 只有部分匹配：章节确实讨论宗教与现代经济的关系，但没有“宗教伦理如何通过日常行为塑造经济制度”这一完整解释对象。因此它保留为部分匹配的 HOLD，而不是把相邻主题误当成 DEEPENING。
- C7 与 K5 的中心对象分别是“把地方多样性作为系统冗余”和“安全工程防线／共因失效”。章节只有全球风险与身份冲突主题，没有这些对象，故两者 REJECT。两项都不应因为可迁移性或跨学科新颖性改为 HOLD。

### 校准判断

Gate 1 同时解决两类错误：它阻止 C7／K5 的跨域类比伪装成原生机制，也不把 C1／C8／C9 等有真实问题入口的候选过早 REJECT。部分匹配只能进入 HOLD，不能进入 CORE／DEEPENING。

## 2. 锚点二：Gate 2 独立分析语法

### 一致性检查

- C1 的“承诺可交易性—交换动作—拒绝／愤怒反应”、C2 的“成本—可见性—可伪造性—合作／排斥”、C3 的“移除神圣来源—权威／异议边界”、C4 的“技术失败—角色分区—整体崩解”、C5 的“价值／分配／执行—成本收益—履约”、C6 的“叙事—组织—强制—反馈”、C8 的“退出—发声—忠诚—纠错”和 C9 的“自治—监督—申诉—跨层履约”均能删除理论名后运行。
- K1、K2、K3、K4、K6、K7、K8、K9、K10 也有可复用的变量链；它们被 HOLD 或 DEEPENING，不是因为语法不存在，而是因为语法在本章的观测承载或作者非等价程度不同。
- C7 与 K5 的安全工程语法在抽象层面成立，但不能在当前章节的原生对象上运行；这正是 Gate 1 与 Gate 2 的联合拦截，不是对安全工程本身的否定。

### 校准判断

“有独立语法”只证明候选不是理论标签，不自动生成 CORE。C1、C8、K7、K8 说明语法独立但关键原文对象／行为仍缺失；这类候选必须继续停在 HOLD。

## 3. 锚点三：Gate 3 作者等价测试

### 一致性检查

- C4 与 C5 通过强非等价测试：C4 新增“失败隔离／承载网络／整体崩解条件”，C5 新增“分配、搭便车、执行以及承诺／行动／结果区分”，都不是把作者身份解释换一个名字。
- C2、C3、C6、K3、K9 通过但主要属于深化：分别新增成本信号、合法化层级、制度反馈、国家制度化链和资源动员通道，但中心仍在解释作者已经给出的仪式、宗教包装或国家忠诚。
- K10 只部分通过：互动过程和双向测量是新增，但“仪式带来团结并让人觉得与他人不同”及其美／丑双向结果已在章节中明确出现。因此它从 v0.2 A 下调为 DEEPENING。
- C1、C8、K7 的语法非等价，但“交换反噬”“退出／发声封锁”没有成为本章已落地的核心结果，故不能绕过 Gate 4 进入 CORE。
- C7 与 K5 不是作者等价的好候选，而是原生对象不成立；它们不能以“理论独立”替代 Gate 1。

### 校准判断

作者等价测试是 v0.3 相对于 v0.1 的必要收紧：新中间条件不等于新核心机制。它也解释了为什么 K10 不能沿用 v0.2 A。反过来，C5 不能因为其主题仍与身份冲突相连就被判为作者等价；关键是它改变了“谁承担成本、谁获得收益、谁能搭便车、如何执行”的解释动作。

## 4. 锚点四：L1／L2／L3 主张强度

### 逐级检查

| 等级 | 本轮对应候选 | 检查结论 |
|---|---|---|
| L1 | C1、C8、C9、K1、K2、K4、K6、K7、K8 | 有原生现象或部分问题入口，但中心行为／过程／对照缺失；只能提出待验证问题。 |
| L2 | C2、C3、C4、C5、C6、K3、K9、K10 | 有独立语法和至少一条变量—结果链，可提出条件机制；必须显式保留未观察的变量、时序、反事实或替代解释。 |
| L3 | 无 | 没有任何候选同时具备决定性变量变化、行为／制度结果、时间顺序或比较／反事实，以及足够的替代解释排除。 |
| L0 | C7、K5 | 中心机制没有原生观测对象，不能形成当前章节的机制锚点。 |

### C5 的特别校准

C5 从 v0.2 的 `HOLD/O1` 调为 `CORE/L2`，不是把它调成 L3。允许它到 L2 的依据是：固定章节直接提出全球问题与地方国家利益的尺度冲突；冻结 Expert 后审计还显示，C5 在回到固定原文时确实保留了价值／分配／执行三分诊断、成本集中而收益分散时的条件预测、承诺与结果的区分以及分摊／监测／履约反事实。这些内容是应用证据，不是旧标签或旧模型分数。

仍然不能写：本章具体国家已经被证明是分配冲突、搭便车已发生、加入补偿一定改善合作。它们需要 L3 级别的成本、收益、时序和对照材料。

### C1 与 C8 的反向校准

C1 的冻结 Expert 课可以讲清不可交易性，但固定原文没有交换提议和反应；C8 的冻结 Expert 课可以讲清退出／发声语法，但固定原文没有退出通道、异议后果和失败持续。两者都只能 L1。这样既避免 v0.1 把课程完整度写成个案已证，也避免把外部框架本身 REJECT。

## 5. 锚点五：Gate 5 产品新增结果

### 一致性检查

- CORE：C4 生成“技术失败／角色收缩／整体崩解”的诊断，C5 生成“价值／分配／执行”诊断和成本分摊反事实；两者都改变产品使用者的下一步判断。
- DEEPENING：C2、C3、C6、K3、K9、K10 都提供受限的分类、组织链、反事实或观察清单，但这些结果主要是作者轨道的精细化，故不包装成 CORE。
- HOLD：C1、C8、C9、K1、K2、K4、K6、K7、K8 仍有取证清单或替代诊断，但产品输出必须是“检查什么”，不能是“本章已经发生什么”。
- REJECT：C7、K5 的潜在工具不能对当前章节提供原生产品动作；把跨域工具列为“新增能力”会越过 Gate 1。

### 校准判断

Gate 5 只问“产品是否能多做一个判断动作”，不问“产品负责人是否接受”。它因此不会把 HOLD 误写为无价值，也不会把有工具价值的 REJECT 候选重新放进当前生产队列。

## 6. 锚点六：四类结果映射

### 最终映射

| 分类 | 候选 | 与六锚点的对应关系 |
|---|---|---|
| CORE | C4、C5（暂定） | 直接原生匹配、语法独立、非作者等价、达到 L2、产品结果独立；两者都停在 L2，不是 L3。 |
| DEEPENING | C2、C3、C6、K3、K9、K10 | 原生匹配、语法和产品结果成立，但新结果主要是作者轨道的机制深化，或作者等价测试只有部分通过。 |
| HOLD | C1、C8、C9、K1、K2、K4、K6、K7、K8 | 问题入口和语法有保留价值，但只到 L1，或中心观测缺失；继续保留但禁止兑现完整种子承诺。 |
| REJECT | C7、K5 | 原生解释对象不成立，中心结果依赖跨域类比，最高 L0。 |

### 分类与主张的关系

- CORE 不等于 L3；本轮 CORE 只有 L2。
- DEEPENING 不等于低质量；它表示有产品增量，但不应占用独立核心机制的承诺位。
- HOLD 不等于理论错误；它表示当前闭集材料没有承载完成承诺所需的决定性环节。
- REJECT 不等于外部理论永久无效；它表示本轮章节不承载该解释对象。

## 7. 争议候选与裁决原因

### C5：v0.2 HOLD → v0.3 CORE（暂定）

这是本轮最重要的校准争议。v0.2 把 C5 的成本／收益／执行观测缺失视为 O1，忽略了“可以用受限机制语言重组原生尺度冲突”和冻结 Expert 后应用已兑现之间的差别。v0.3 允许 C5 以 L2 CORE 保留，但要求所有输出都写成“可按价值／分配／执行检查”，不得写成“本章已证分配失败”。这修正 v0.2 过严，同时保留 L3 防线。

### C4：v0.2 A、v0.1 B → v0.3 CORE

C4 的“技术权威退场与身份权威延续并存”是章节直接并置的结构，不只是模型提出的标签；角色分区和整体崩解条件构成新的核心诊断。它仍只有 L2，因为组织承载网络的变化没有被观察。CORE 的依据是非等价机制结果，不是更强的因果证据。

### K10：v0.2 A → v0.3 DEEPENING

K10 的优势是章节同时给出团结／希望／慈爱和区分／歧视／丑陋，因而确实超过了纯 L1；但作者已经明确写出仪式让人团结并觉得与他人不同。涂尔干式互动过程和测量拆分是有价值的深化，不足以通过 CORE 所需的强非等价测试，也没有 L3 的现场互动与后果记录。

### K9：v0.2 B → v0.3 DEEPENING

K9 不能因专业入口而变 CORE，也不能因缺少财政时间序列而退回 HOLD。它有章节直接给出的国家身份—忠诚—牺牲链，并新增国家组织、资源提取和成本分配的 L2 诊断；但财政、征募、行政覆盖、群体成本和反事实缺失，且中心仍深化作者国家神道轨道，故 DEEPENING。

### C1 与 C8：保持 HOLD

C1 的“神圣化”不等于已观察到“补偿反噬”；C8 的“忠诚／牺牲”不等于已观察到“退出受阻／发声封锁／制度失败持续”。两项都有独立语法，故不能 REJECT；两项都只有 L1，故不能 CORE 或 DEEPENING。

### K8：保持 HOLD 而非 REJECT

K8 的中心日常伦理—经济行为链没有在章节出现，但章节确实提出宗教与现代经济的作用问题并提供政策／伦理入口。因此它是部分原生匹配的待取证方向。v0.3 用 HOLD 表示“尚不能承载”，而不是把相邻主题误判为完全不匹配；若未来仍没有行为中介材料，才没有升级理由。

### C7 与 K5：保持 REJECT

两项都不只是观测缺口：它们缺的是中心原生解释对象。C7 需要把地方身份当作安全系统冗余，K5 需要事故链和共因失效；当前章节没有这些对象。把它们降为 HOLD 会重新制造 v0.1 的跨域过宽问题。

## 8. 结论

本轮校准后的最小一致规则是：

`原生问题匹配` 决定能否留在本章；`独立语法` 决定是不是换名重述；`作者等价测试` 决定能否称为独立 CORE；`L1/L2/L3` 决定最多能说到哪里；`产品新增结果` 决定是否值得转成后续使用动作；四类分类只是在这五道门之后汇总，不替代任何一道门。

因此，v0.3 的暂定结果为：C4、C5 为 L2 CORE；C2、C3、C6、K3、K9、K10 为 L2 DEEPENING；C1、C8、C9、K1、K2、K4、K6、K7、K8 为 L1 HOLD；C7、K5 为 L0 REJECT；全体没有 L3 个案已证。

本文件不创建产品卡、不生成用户报告、不改变正式仓库文件，也不把任何候选送入 Expert、Writer 或 Reader。
