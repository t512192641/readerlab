# ReaderLab v0.3 全量复筛：C1-C9 与 K1-K10

本表严格使用统一字段。`L1/L2/L3` 是当前白名单材料允许的最高主张强度，不是模型分数；`CORE/DEEPENING/HOLD/REJECT` 是 v0.3 候选分类。旧 Expert 的审核内容只用于确认应用是否兑现及缺口，不构成自动晋级。

## C1｜神圣承诺的不可交易化与物质激励反噬

**候选 ID**：C1（成员：`BASELINE-01`、`S1-01`、`S1-02`）。

**外部知识对象**：神圣价值与禁忌交换框架，以及不可交易承诺中的物质激励反噬。

**原生问题**：章节提出宗教身份何时把政策和牺牲变成不可协商的承诺，以及普通利益交换为何可能失效。

**当前章是否存在该问题**：部分存在。章节有“神圣又永恒的教条”、神选国家、国家忠诚和神风特攻队牺牲，但没有补偿提议、加码前后反应或拒绝定价。

**独立分析语法**：先区分可交易偏好、边界不明承诺和神圣化承诺；再改变金钱、福利、荣誉或家属补偿，观察接受、拒绝、愤怒、妥协空间或参与意愿，并排除强制、同侪压力和宣传。

**核心新增结果**：在神圣化条件下，普通补偿可能被理解为冒犯或收买，拒绝和动员反而增强；但这只能作为条件预测，不能写成国家神道案例已发生。

**作者等价测试**：通过但仅部分落地。不可交易性、交换禁忌和反噬预测不是作者的“宗教制造身份／忠诚”结论；然而当前章无法观察预测所需的交换事件。

**可成立的最高主张级别**：L1。冻结 Expert 审计确认框架课的语法和独立案例成立，但固定原文应用只部分兑现；`SOURCE_BLOCKED` 也不能补上原文缺失的行为观测。

**产品新增能力**：提供“不要立即用钱讨价还价”的诊断问题，并列出识别神圣化、补偿反应和替代解释的取证清单；不能输出该案例的反噬结论。

**v0.1/v0.2 旧分类**：v0.1：A｜核心借脑候选；v0.2：`HOLD_OBSERVATION_GAP`。

**v0.3 新分类**：`HOLD`。

**判断理由**：它不是因为理论无效而 HOLD，而是因为“神圣”不能替代“不可交易”的实际反应证据。保留 L1 能防止 v0.1 过宽，也保留未来针对交换事件的取证入口；不能借冻结 Expert 通过把它升为 CORE 或 L3。

## C2｜仪式作为昂贵、可信或被迫的承诺信号

**候选 ID**：C2（成员：`BASELINE-02`、`S4-01`）。

**外部知识对象**：昂贵信号与可信承诺机制。

**原生问题**：章节问仪式为何能同时带来团聚、信任、边界和牺牲，以及这些效果是否同一强度。

**当前章是否存在该问题**：直接存在。章节列出服饰、祷歌、禁忌、每日／每周仪式，以及从日常团聚到高代价牺牲的现象；没有比较实际成本和结果变化。

**独立分析语法**：把仪式拆为成本、公开可见性、可伪造性、退出代价和自愿／强制；再比较成本梯度与群内合作、群外排斥、伪装和误判之间的条件关系。

**核心新增结果**：可以把仪式分为低成本装饰、重复公开承诺和高成本难伪装行动，并预测高成本不必然等于可信：强制或退出受罚时可能转为表面服从和内部误判。

**作者等价测试**：通过，但新增主要是作者“仪式划界／团结”轨道的中间机制和边界，不改变原文的基本解释对象。

**可成立的最高主张级别**：L2。章节有仪式对象和团结／区分结果，可支持受限的成本—可信度分析；没有成本量化、观察者—受益者链或前后对照，不能到 L3。

**产品新增能力**：帮助读者判断一个仪式是在筛选承诺、生产合作，还是制造胁迫服从，并提出成本、退出和替代解释的核验问题。

**v0.1/v0.2 旧分类**：v0.1：A｜核心借脑候选；v0.2：`B_DEEPENING`。

**v0.3 新分类**：`DEEPENING`。

**判断理由**：新语法清楚且有 L2 价值，但其中心仍是把作者已写出的仪式团结与边界细分为成本条件；按 Gate 3 只能作为受限深化，不能伪装成独立 CORE。

## C3｜追认式包装与构成式合法化

**候选 ID**：C3（成员：`S2-01`）。

**外部知识对象**：合法化层级与象征秩序的构成性作用。

**原生问题**：章节区分宗教是否真的提供政策知识，还是在既定政策之后提供权威包装；同时又写到国家重造神道并组织忠诚。

**当前章是否存在该问题**：直接存在。伊朗经济政策段落给出追认式经文包装，国家神道段落给出更深的国家／领袖神圣化；但没有移除神圣来源后的权威、异议和惩罚对照。

**独立分析语法**：保持政策内容不变，反事实移除神圣来源；比较谁仍有命令资格、谁仍有异议资格、违抗是否仍被定义为背叛，以及惩罚边界是否变化。

**核心新增结果**：形成“追认式包装／构成式合法化”二分：前者撤掉神圣理由后制度仍运行，后者撤掉后统治资格、牺牲义务或异议者身份会失效。

**作者等价测试**：通过但属于深化。二分反事实和权威／异议边界不是作者原结论；不过候选仍在解释作者已给出的“宗教包装政策”和“国家神道维持忠诚”。

**可成立的最高主张级别**：L2。两种现象入口都在章节中，足以形成受限分层；缺少同一制度的移除对照，不能断言国家神道已属于构成式合法化。

**产品新增能力**：让读者不再把所有宗教背书视为同一强度，并能用移除来源的反事实检查其是否改变命令、异议和制裁。

**v0.1/v0.2 旧分类**：v0.1：A｜核心借脑候选；v0.2：`B_DEEPENING`。

**v0.3 新分类**：`DEEPENING`。

**判断理由**：它有真实新增的诊断动作，但当前应用仍是作者轨道上的合法化强度拆分；保留 L2，拒绝把“国家神道存在”直接等同于构成式秩序。

## C4｜局部技术失败为何不必然导致整体神圣秩序崩解

**候选 ID**：C4（成员：`S2-02`）。

**外部知识对象**：可信性结构、角色分区与局部失败后的制度韧性。

**原生问题**：章节说明宗教在农业、医疗等技术领域失败并退场，却继续在身份、仪式、道德和国家认同上发挥作用。

**当前章是否存在该问题**：直接存在，且技术权威退场与身份权威延续被同章并置；章节没有组织密度、仪式频率、代际传递或退出成本的变化。

**独立分析语法**：区分技术命题失败、角色收缩、身份／道德承诺失败和整体秩序失效；再检查组织、仪式、日常互动和代际网络是否把失败隔离在技术角色内。

**核心新增结果**：技术失败不自动推出整套神圣秩序崩解；在角色分区且承载网络稳定时可能保留身份权威，若失败进入身份承诺且承载网络衰退，才更可能连锁去合法化。

**作者等价测试**：通过。作者给出“技术失地／身份延续”的现象和解释，候选新增了失败隔离、承载网络和崩解条件，而不是只换称“韧性”。

**可成立的最高主张级别**：L2。章节已提供两类权威并存的连接，支持受限核心机制；承载网络的实际变化和因果顺序缺失，不能到 L3。

**产品新增能力**：把“宗教失败了却没有整体消失”拆成角色收缩、命题修补和整体崩解三种诊断，提示需要观察哪些承载网络。

**v0.1/v0.2 旧分类**：v0.1：B｜高质量原文深化；v0.2：`A_CORE`。

**v0.3 新分类**：`CORE`。

**判断理由**：它满足直接原生问题、独立语法、非等价新结果和 L2 条件；CORE 只表示可保留的受限核心，不表示“承载网络导致韧性”的 L3 个案解释已经证明。

## C5｜全球公共品中的价值冲突、分配冲突与执行冲突

**候选 ID**：C5（成员：`S3-01`）。

**外部知识对象**：全球公共品与集体行动框架，包括外溢、成本收益分布、搭便车、否决权、补偿、监督和履约。

**原生问题**：章节明确提出全球变暖、核战争、生态崩溃和科技颠覆只能从全球处理，却同时写到宗教／民族国家把行动拉回本国利益。

**当前章是否存在该问题**：直接存在。章节提供全球问题与地方动员的尺度错位、共同价值与国家利益的冲突；没有把每一方的成本、收益、搭便车和执行结果逐项量化。

**独立分析语法**：先确认是否存在公共品与跨境外溢，再分别检查价值冲突、分配冲突和执行冲突；追踪谁承担当期成本、谁取得跨境收益、谁可搭便车、谁有否决权、是否有补偿与可信履约。

**核心新增结果**：即使各方共享普世价值，若成本集中于国内、收益跨境分散、搭便车空间大且缺少分摊／监督／履约，政策仍可能民族化；加入可执行分摊后，身份未必继续是唯一阻断机制。

**作者等价测试**：通过且达到 CORE 所需的非等价标准。作者把问题主要归因于身份和民族主义；候选加入分配、搭便车、执行和承诺／行动／结果区分，改变了诊断对象。

**可成立的最高主张级别**：L2，暂定。固定章节能承载全球—地方尺度冲突和“身份不是唯一解释”的受限机制应用；它没有证明本章具体国家已经满足某种成本分布，也没有证明补偿会改善合作，故不是 L3。

**产品新增能力**：把“价值不一致”与“分配不公平／执行不可信”分开，指导读者画出成本—收益—搭便车—履约表，并生成成本分摊后的反事实。

**v0.1/v0.2 旧分类**：v0.1：A｜核心借脑候选；v0.2：`HOLD_OBSERVATION_GAP`。

**v0.3 新分类**：`CORE`（暂定）。

**判断理由**：v0.2 把缺少每一项分配数据等同于只能 L1，造成一次已记录的过度保守；冻结 Expert 后审计显示 C5 的非作者等价应用、三分诊断、条件预测和反事实已经兑现。v0.3 因此允许它以 L2 CORE 保留，但明确“L2 可成立不等于本章个案的 L3 成本／执行机制已证”，也不因 `PRODUCT_READY` 自动晋级。

## C6｜叙事供给、组织嵌入、强制排除与制度反馈

**候选 ID**：C6（成员：`S3-02`）。

**外部知识对象**：历史制度主义的政策反馈与国家宗教制度化。

**原生问题**：章节描述日本选择、重造和压制传统元素，并把国家神道与忠诚、牺牲和现代国家连接起来。

**当前章是否存在该问题**：直接存在。章节有官方版本、地方传统被压制、元素按忠诚需要被采纳和忠诚结果；没有学校、官僚、财政、晋升、制裁或组织入口的过程证据。

**独立分析语法**：拆分定义正统的权力、替代项压制、组织执行、资源／晋升奖励和制裁；比较忠诚来自叙事说服、强制排除还是制度反馈。

**核心新增结果**：只有当叙事选择与组织入口、资源配置、制裁和重复执行同步，才可把动员归因于制度反馈；相同神话在缺少这些通道时不应预测同等忠诚。

**作者等价测试**：通过但属于深化。四段中介链和“文本效果≠制度化效果”是新增；中心案例和原生结果仍是作者的国家神道—忠诚轨道。

**可成立的最高主张级别**：L2。章节给出选择、压制和忠诚的连接入口，允许条件化拆解；因果时序和资源反馈缺失，不能到 L3。

**产品新增能力**：把“国家用宗教动员”拆成叙事、组织、强制和反馈四个检查点，防止把宣传文本直接当作动员原因。

**v0.1/v0.2 旧分类**：v0.1：B｜高质量原文深化；v0.2：`B_DEEPENING`。

**v0.3 新分类**：`DEEPENING`。

**判断理由**：它达到 L2 并有清晰新动作，但没有跨出作者案例轨道形成 CORE；保持 DEEPENING 同时允许使用其组织化检查，不把国家能力因果写成已证。

## C7｜全球协调收益与共同失效风险的系统架构权衡

**候选 ID**：C7（成员：`S4-02`）。

**外部知识对象**：安全工程中的紧耦合、共同原因失效、纵深防御、故障隔离和冗余。

**原生问题**：章节提出全球风险需要全球合作、地方身份可能造成分裂。

**当前章是否存在该问题**：只有主题近邻，没有安全工程的原生问题对象。章节没有防线拓扑、事故链、失效模式、预警、恢复或地方多样性降低传播的材料。

**独立分析语法**：定义顶层风险，画出技术／政策／协调／监测／恢复防线，检查防线独立性、共同原因和局部隔离，再比较统一方案与异质方案。

**核心新增结果**：在安全工程内部是有辨识度的“统一协调可能增加共同失效风险”的反事实，但当前章节不能把地方身份映射为可靠性冗余。

**作者等价测试**：语法本身独立，但作者等价测试无法在本章完成，因为中心解释对象不是作者的“身份认同”而是外部系统安全；连接只能靠类比。

**可成立的最高主张级别**：L0。不能从当前材料得到原生的 L1 安全机制锚点。

**产品新增能力**：若有独立安全系统材料，可提供防线与共因审计；对本章不能提供合格的语义新增结果。

**v0.1/v0.2 旧分类**：v0.1：B｜高质量原文深化；v0.2：`C_REJECT`。

**v0.3 新分类**：`REJECT`。

**判断理由**：这是 v0.2 正确识别的 O0 类型：全球风险主题不等于系统可靠性对象。没有新增的原生材料时，保留它会把跨域比喻冒充机制。

## C8｜忠诚对退出、发声与纠错通道的影响

**候选 ID**：C8（成员：`S5-01`）。

**外部知识对象**：Hirschman 的退出／呼吁／忠诚框架及组织反馈机制。

**原生问题**：候选要解释高忠诚、牺牲、退出代价、异议表达和错误纠正如何相互作用。

**当前章是否存在该问题**：只有部分存在。章节有国家忠诚、牺牲和拒绝过度民族主义者缺少政治权力，但没有成员退出、发声渠道、异议惩罚、纠错或失败持续的过程。

**独立分析语法**：分别编码关系衰退、退出通道、退出代价、发声保护、异议后果和忠诚对行动顺序的影响；比较高忠诚／受保护发声、高忠诚／被封锁发声、低忠诚／易退出。

**核心新增结果**：退出受阻且发声封锁时，制度失败可能持续、成员可能接受高代价服从；但本章没有三类状态的记录，不能把国家忠诚直接推出这些结果。

**作者等价测试**：通过但应用不足。退出／发声是独立语法；固定原文应用主要回到“宗教退出技术／政策功能”和忠诚消歧，没有兑现组织分类。

**可成立的最高主张级别**：L1。冻结 Expert 审计确认课程和迁移方法合格，但固定原文应用与种子承诺均部分兑现；`PRODUCT_READY` 不能替代退出与发声证据。

**产品新增能力**：提供纠错通道的待观察问题，帮助区分忠诚、沉默、服从和无法退出；不能判定本章制度是否已封锁发声。

**v0.1/v0.2 旧分类**：v0.1：A｜核心借脑候选；v0.2：`HOLD_OBSERVATION_GAP`。

**v0.3 新分类**：`HOLD`。

**判断理由**：它有明确独立价值，但缺失的是中心机制变量而非边缘细节。保持 HOLD 是对“忠诚≠发声封锁”的硬保护，也与冻结 Expert 后审计的部分兑现一致。

## C9｜地方共同体与全球规则之间的嵌套治理接口

**候选 ID**：C9（成员：`S5-02`）。

**外部知识对象**：多层嵌套治理、地方自治、集体选择、相互监督、申诉和渐进制裁。

**原生问题**：章节提出全球性问题与地方宗教／民族身份之间的冲突，并以欧盟的融合与移民压力作例子。

**当前章是否存在该问题**：部分存在。章节有全球—地方冲突，但没有地方共同体参与高层规则、监督、申诉、冲突解决或成为执行资源的实际运行。

**独立分析语法**：识别共同标记的神圣对象与成员边界 → 观察周期性共同参与和共享情感 → 重新确认集体表象与成员资格 → 分别记录内部团结、对外排斥和越界制裁。

**核心新增结果**：同一仪式可能同时生产内部团结与外部排斥；但章节本身已给出“亲密／慈爱”与“区分／丑陋”的双向描述，新增更多是互动过程和测量拆分，而不是全新方向。

**作者等价测试**：部分通过。独立分析语法和双向测量有新增，但“仪式让人团结并与他人不同”已是作者明说的结果，因此不满足 CORE 的强非等价要求。

**可成立的最高主张级别**：L2。章节有对象、边界和双向结果入口，可提出受限互动机制；没有参与过程和后果记录，不能到 L3。

**产品新增能力**：把仪式效果拆成共同在场、共享情感、成员资格、制裁、内聚和外排六个观察项，避免把仪式直接写成善或稳定团结。

**v0.1/v0.2 旧分类**：v0.1：不适用；v0.2：`A_CORE`。

**v0.3 新分类**：`DEEPENING`。

**判断理由**：K10 的 v0.2 A 主要抓住了完整现象入口，但 v0.3 Gate 3 要求新结果不能只是作者已说出的双向结果；将其调为 DEEPENING 可保留互动语法和 L2 价值，同时避免把“仪式存在＋双向描述”写成核心因果机制或 L3。
