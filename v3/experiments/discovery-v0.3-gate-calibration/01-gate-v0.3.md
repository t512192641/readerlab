# ReaderLab v0.3 Gate：语义阶段 A 候选门槛

## 0. 适用范围与证据边界

本门槛用于本轮闭集材料中的 v0.1 `C1-C9` 与 v0.2 `K1-K10` 重审。它判断的是：一个候选能否在当前章节中保留为受限的语义增量，以及最多可以对该章节说到哪一级；它不是外部理论核验、因果证明、产品接受或 Writer／Reader 许可。

本轮只允许使用：固定章节 `source.xhtml`；v0.1 的原始种子、机制簇轻筛和 Expert 后审计；v0.2 的门槛复核、匿名机制簇审查、揭盲比较、预测检查和十份 raw。冻结 Expert 文件只可作为“应用是否已兑现、哪些环节仍缺失”的证据，不能因为 `TEACHING_PASS`、`PRODUCT_READY` 或旧模型分数自动晋级。

## 1. v0.3 要修正的两个方向

v0.1 的 A/B/C 轻筛把“外部机制独立、能生成新分类、可迁移”误当成“当前章节已经能承载该候选的核心结果”，因此容易把 `L1` 现象锚点写成个案机制已成立。

v0.2 的原文观测承载测试又把“完成全部种子承诺所需的每个决定性观测”作为进入 `O2` 的近乎必要条件，因而把 C5 这类已经能在固定原文上完成受限、非作者等价应用的候选暂时压成 HOLD。v0.3 将“可提出受限机制主张”和“个案已证”拆开：缺少个案行为、时间顺序或反事实，不能到 `L3`；但不必因此把一个已经有独立语法、非等价结果和冻结应用证据的 `L2` 候选全部打回 `L1`。

## 2. 五道 Gate

### Gate 1：原生问题匹配

候选必须回答当前章节真正提出的问题，而不是只共享主题词。检查三件事：

1. 章节是否明确提出了该问题的对象、冲突或结果入口；
2. 候选的分析对象是否仍是这个问题，而不是把章节当作任意例子来承载另一个问题；
3. 候选是否能指出章节中的原生锚点，以及该锚点缺什么。

判定分三档：

- **直接匹配**：章节同时给出候选对象与至少一个相关结果入口；
- **部分匹配**：章节只有相邻问题或上游主题，尚能形成待取证问题；
- **不匹配**：中心解释对象只能靠外部材料或跨域比喻导入。

直接匹配是进入 CORE／DEEPENING 的必要条件；部分匹配最多进入 HOLD；不匹配通常进入 REJECT。

### Gate 2：独立分析语法

删去理论、人名、书名和宗教标签后，候选仍必须能写成可重复运行的语法：

`解释对象 → 关键变量 → 因果动作或比较 → 可观察结果 → 边界／替代解释`。

至少要能回答：看什么、变量怎样变化、为什么会得到不同结果、什么情况会使预测失效。只有“换一个名称重说宗教造成身份认同／仪式划界／民族主义忠诚”的候选，不通过 Gate 2。

### Gate 3：作者等价测试

把外部理论名和术语全部删除，保留候选的对象、变量、动作和结果，再与作者在本章已经明确给出的解释逐项对照。

- 如果剩下的中心结果仍只是“宗教划分我们／他们”“宗教为政策包装”“国家改造宗教服务忠诚”“全球身份与地方身份冲突”，候选与作者等价，不得成为 CORE；没有可保留的新结果时 REJECT。
- 如果候选增加了作者未给出的中间条件、边界、替代解释或反事实，但仍主要解释作者已经给出的轨道，归为 DEEPENING。
- 如果候选改变了判断对象或解释动作，能提出作者原文不能直接推出的核心分类、条件结果或反事实，且不依赖未声明的外部事实，才可能成为 CORE。

作者等价测试只判断“是否新增”，不判断新增机制是否已经被个案证明；后者由 Gate 4 处理。

### Gate 4：L1／L2／L3 主张强度

主张等级是证据上限，不是质量分数。所有候选都必须把“本章观察到的内容”“候选提出的条件机制”“本章个案已证的内容”分开写。

#### L1｜现象锚定／待验证问题

章节直接出现相关对象、表述或结果入口，但缺少完成机制所需的关键反应、过程、比较或替代解释。允许的写法是：

> 本章出现了 X；因此可以提出检查 Y 的问题。不能写成 X 已经由该机制导致了 Z。

L1 可以保留为 HOLD，但不能承诺完整种子结果。

#### L2｜受限机制主张

候选已有独立语法、非作者等价的结果和至少一条可追踪的变量—结果链，足以提出一个明确的条件化机制判断或反事实；但仍然明确标注哪些变量、行为反应、时间顺序或对照没有被当前章节直接观察。L2 允许“在 A、B 条件下，C 更可能发生”的受限主张，不允许把 A、B、C 写成该章节个案已经证实。

L2 的证据可来自两类且必须逐项写明：

1. 固定章节自身已经把关键对象、关系入口和结果方向连接起来；或
2. 冻结 Expert 后应用已经把独立语法非等价地落回固定章节，并明确保留缺口。

第二类只帮助校准“能否形成 L2 的应用主张”，不把独立案例或 Expert 的教学通过改写成原文个案证据。

#### L3｜个案已证／较强产品主张

除了 L2 条件外，还必须在允许材料中看到候选所需的决定性观测：关键变量的实际变化、行为或制度结果、时间顺序、比较／反事实，且对强制、利益、宣传、阶级或其他替代解释有足够区分。只有 L3 才能写“本章这个案例显示／证明该机制在此处发生”，或把条件预测升级为该个案的已成立解释。

本轮闭集材料没有任何 C/K 候选达到 L3。L1／L2 可成立，不等于 L3 个案已证。

### Gate 5：产品新增结果

候选必须为产品使用者新增至少一种可执行结果：

- 新的诊断分类；
- 新的条件预测；
- 新的反事实比较；
- 新的观测清单或替代解释排查；
- 新的迁移边界或失败条件。

“读者会更换一个理论名称”“把作者的身份认同换称为合法化／制度化”“得到一个没有判断动作的知识标签”不算产品新增结果。通过 Gate 5 也只表示产品可得到一个受限的新动作，不表示产品负责人已经接受，更不表示成品质量已经验证。

## 3. 四类结果

### CORE

Gate 1 直接匹配，Gate 2 通过，Gate 3 通过且新增结果不只是作者轨道的中间补充，Gate 5 通过，并达到至少 L2。CORE 是“可保留的受限核心机制主张”，不是个案证明；若最高等级是 L2，后续文案必须保留条件句和缺口，不得写成 L3。

### DEEPENING

Gate 1 直接匹配，Gate 2 通过，Gate 5 有新增结果，但 Gate 3 显示它主要是对作者已有解释的机制深化、边界补全或组织化拆解；或者独立语法成立但尚不足以承担独立 CORE 解释。一般可达到 L2，但产品定位是“受限深化”而不是核心借脑。

### HOLD

Gate 1 至少部分匹配，候选值得保留且通常通过 Gate 2／Gate 3，但只能到 L1，或到 L2 所需的决定性原文观测／应用落地仍缺失。HOLD 不是理论错误，也不是产品否定；它禁止当前波次把未观测的行为、时间顺序、反事实或机制反转写成已成立结果。

### REJECT

Gate 1 不匹配、Gate 2 不成立、Gate 3 只剩作者等价重述，或中心结果只能靠与章节无关的跨域类比成立。REJECT 只表示在本轮白名单材料和当前语义阶段不进入候选队列；若将来有新的、明确授权的原生材料，应重新评估，不能沿用本轮分类。

## 5. 关键禁止语句

- “原文写到神圣，所以该案例已证明不可交易。”
- “原文写到忠诚和牺牲，所以已证明退出受阻、发声封锁或制度失败持续。”
- “原文写到全球问题与国家利益冲突，所以已证明公共品的成本集中、搭便车或执行失败。”
- “Expert 教学通过／技术终端为 `PRODUCT_READY`，所以候选自动 CORE 或 L3。”
- “L1 或 L2 的条件机制已经是该个案的事实解释。”

本门槛的最小安全句式是：`章节已观察到……；候选新增的受限判断是……；但决定 L3 所需的……仍未观察到。`
