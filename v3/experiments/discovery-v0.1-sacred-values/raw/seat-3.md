# 扣除作者贡献

1. 作者已经解释：传统宗教退出技术与政策知识生产后，仍能借仪式、神话和重新诠释划分“我们／他们”，为民族国家制造认同、合作与忠诚；国家也能改造宗教来服务现代制度。
2. 不能仅换理论名称再次提交：宗教主要处理身份认同、仪式维持群体边界、宗教政策立场来自现代政治运动、宗教侍奉民族主义，以及现代科学和经济学承担技术与政策判断。
3. 尚未解释：全球利益为何难以压过地方成本与否决权；国家改造宗教时，叙事、强制、组织渠道和资源投入各自贡献多大；同样可被重新诠释的传统为何并不必然产生同等忠诚。

Seed ID：S3-01
发现席位：S3｜政治经济学
原文锚点：“核战争、生态崩溃和科技颠覆等问题也只能从全球角度来解决”，但宗教领袖仍鼓励本国人优先考虑本国利益。
作者已提供的解释：宗教认同服务民族主义，把共同文明分割为敌对阵营；具有共通愿景的宗教人士在政治上缺少权力。
外部知识对象：集体行动与全球公共品供给框架——按收益可排他性、成本集中度、搭便车空间和参与者否决权分析合作失败。
独立分析语法：不先问某宗教是否宣称普世价值，而问谁承担当期成本、谁获得跨境收益、谁能搭便车、谁有权阻止承诺，以及是否存在补偿和可信执行机制。
预计生成剩余：形成“价值冲突／分配冲突／执行冲突”三分诊断；预测即使各方共享普世价值，只要成本集中于国内、收益分散到全球且缺少补偿与执行，政策仍会民族化；反事实是加入可执行的成本分摊和补偿后，地方认同未必继续阻断合作。
连接依据：原文已指出问题尺度是全球、政治动员尺度却是国家，但没有拆解这种尺度错位背后的收益、成本、搭便车和否决结构。
框架潜力：可迁移到气候、核扩散、迁移和跨国技术治理，用同一组问题区分“认同造成不合作”与“制度没有把合作变得可承受”。
记忆缺口：需要后续核验该框架的严格概念边界，并寻找能区分价值表态与真实成本分担的比较材料；当前章节未提供各方成本、收益或否决结构数据。

Seed ID：S3-02
发现席位：S3｜政治经济学
原文锚点：日本国家“创造了官方版本的神道教，同时打压了许多地方传统”，筛选多种元素巩固国家忠诚，并被作者用于解释神风特攻队式牺牲。
作者已提供的解释：现代国家能够重新改造古老宗教，以共同神话和仪式强化国家认同，并把这种忠诚接到现代科技与战争机器上。
外部知识对象：历史制度主义的政策反馈框架——制度一旦配置权威、组织入口和资源，就会塑造受益者、执行者与后续可行选择，反过来巩固制度本身。
独立分析语法：把“宗教叙事有效”拆成四个可检验环节：谁获得定义正统的权力、哪些地方替代项被压制、哪些组织反复执行仪式、哪些资源和晋升机会奖励服从；再判断忠诚来自叙事说服还是制度反馈。
预计生成剩余：生成“叙事供给／组织嵌入／强制排除／反馈自固化”四段机制；预测相同神话在缺少统一执行渠道和替代项压制时，动员强度会下降；新判断条件是只有观察到组织入口、资源配置或制裁随官方宗教同步变化，才能把效果归于制度化而非文本本身。
连接依据：原文同时给出国家筛选、地方传统受压制和高度忠诚，却直接从改造后的宗教跳到动员结果，尚未区分叙事内容与国家组织权力的边际贡献。
框架潜力：可用于比较国家宗教、官方纪念仪式、组织文化和意识形态教育，追踪某套象征如何从一次宣传变成自我强化的制度。
记忆缺口：需要后续补足政策反馈的识别方法及反例；当前章节没有学校、官僚、财政、惩罚或晋升渠道的过程证据，不能据此断言具体反馈链已经成立。
