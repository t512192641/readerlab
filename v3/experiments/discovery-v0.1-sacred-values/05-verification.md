## C1｜神圣承诺的不可交易化与物质激励反噬

- 检索词：`sacred values taboo trade-offs Tetlock original paper`；`material incentives sacred values backfire political conflict`。
- 关键来源：Tetlock 的 PubMed 条目与摘要，https://pubmed.ncbi.nlm.nih.gov/12860191/；Ginges 等关于物质激励可能反噬的 PNAS 研究条目，https://pubmed.ncbi.nlm.nih.gov/17460042/。
- 核验结论：对象真实存在；“神圣价值与世俗价值的交易可被视为禁忌”以及“物质激励在部分神圣冲突中可能反噬”与来源摘要一致。
- 边界：不能外推为所有宗教、所有身份立场或所有补偿都会反噬；当前章节本身不能证明具体人物/事件确实以神圣价值机制为主因。
- 结果：`PASS_WITH_BOUNDARY`；允许作为固定框架进入 Expert，要求课程区分研究结果、当前文本推论与未知。

## C5｜全球公共品的成本—执行结构

- 检索词：`global public goods collective action free riding climate policy`；`cost distribution enforcement global public goods`。
- 关键来源：Buchholz 与 Sandler 的《全球公共品：综述》，https://www.aeaweb.org/articles?id=10.1257/jel.20191546；Nordhaus 的《气候俱乐部：克服国际气候政策中的搭便车》，https://www.aeaweb.org/articles?id=10.1257/aer.15000001&page=116；Bättig 与 Bernauer 关于国家制度与气候合作的研究，https://www.cambridge.org/core/journals/international-organization/article/abs/national-institutions-and-global-public-goods-are-democracies-more-cooperative-in-climate-change-policy/3B04986C13488B291DF27F312DC23665。
- 核验结论：全球公共品的非排他/非竞争、跨境外溢、搭便车与制度安排确有稳定文献对象；气候合作中“承诺/实际结果”、成本分配和执行约束的区分也有实证研究支撑。
- 边界：把全球问题解释成“身份冲突”并不总是错误或充分；分配冲突、国内利益和制度执行可能与搭便车模型竞争。C5 的三分诊断是待应用的候选组织方式，不是来源原有的固定术语或已验证结论。
- 结果：`PASS_WITH_BOUNDARY`；允许作为固定框架进入 Expert，要求避免把本章问题直接化约为单一搭便车模型。

## C8｜退出—呼吁—忠诚与纠错通道

- 检索词：`Hirschman Exit Voice Loyalty original book`；`loyalty voice exit organization decline`。
- 关键来源：哈佛大学出版社书目/内容说明入口，https://www.harvard.com/book/9780674276604；澳大利亚国立大学对 Keith Dowding 相关综述章节的书目与摘要，https://researchportalplus.anu.edu.au/en/publications/albert-o-hirschman-exit-voice-and-loyalty-responses-to-decline-in/；Oxford DOI，https://doi.org/10.1093/oxfordhb/9780199646135.013.30。
- 核验结论：赫希曼 1970 年著作及 Exit/Voice/Loyalty 三概念真实存在；退出与内部发声的区别，以及忠诚可能延缓退出并让发声发挥作用，与书目说明及综述一致。
- 边界：忠诚不必然等于沉默或盲从；把神风特攻队、宗教民族主义或国家神道映射为该框架的应用是当前实验推论，不是赫希曼原书直接研究结论。
- 结果：`PASS_WITH_BOUNDARY`；允许作为固定书籍框架进入 Expert，必须把原书概念、ReaderLab 教学组织和当前章应用推论分开。
