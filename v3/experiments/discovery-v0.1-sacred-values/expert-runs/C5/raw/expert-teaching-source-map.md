# C5 专家教学来源映射

## 来源身份

| source id | 身份 | 本稿实际用途 |
|---|---|---|
| C5-TEXT | 固定原文 `inputs/source.md` | 原文的技术／政策／身份认同区分；宗教与民族认同的关系；全球问题与地方认同之间的张力；原文自身保留的例外 |
| C5-S1 | 沃尔夫冈·布赫霍尔茨与托德·桑德勒（2021），《全球公共品：综述》 | 全球公共品的跨境外溢；收益非竞争性、收益非排他性、贡献聚合方式、外溢范围；联盟、制度安排与集体行动问题 |
| C5-S2 | 威廉·诺德豪斯（2015），《气候俱乐部：克服国际气候政策中的搭便车》 | 搭便车导致低减排稳定联盟；对非参加者设置一定贸易惩罚可能改变联盟激励；该结论的模型边界 |
| C5-S3 | 米歇尔·贝蒂格与托马斯·贝尔瑙尔（2009），《国家制度与全球公共品：民主国家在气候变化政策中更合作吗？》 | 区分政策承诺与实际结果；民主制度与政策承诺的正向关系及与排放结果的模糊关系；并列检查言辞和行动 |
| C5-RL | ReaderLab 教学整理 | “价值冲突／分配冲突／执行冲突”三类教学组织、六问迁移提示、三镇水库案例 |
| C5-APP | 当前原文应用推论 | 身份可改变责任范围和付费意愿；共同价值不能自动解决分配与执行；神圣或普世语言包装不等于产生实际结果 |

## 主要内容逐项映射

| 教学内容 | 主要依据 | 归属说明 |
|---|---|---|
| 全球公共品框架原生处理跨境外溢、公共品供给与集体行动 | C5-S1 | 后续研究综述，不是固定原文主张 |
| 非竞争性、非排他性、贡献聚合方式与外溢范围四项属性 | C5-S1 | 来源文献框架 |
| 成本集中、收益分散会产生搭便车诱因 | C5-S1、C5-S2 | 来源框架的普通中文转述 |
| 无制裁时稳定联盟减排水平低；一定贸易惩罚可能支持更大稳定联盟 | C5-S2 | 诺德豪斯特定模型和经验建模结论，未外推为通用处方 |
| 政策承诺与排放结果必须分开 | C5-S3 | 来源文献的核心经验提醒 |

| 技术、政策、身份认同的三类问题 | C5-TEXT | 固定原作者内容 |
| 宗教在技术和现代政策上直接作用有限，却能强烈塑造群体边界 | C5-TEXT | 固定原作者内容 |
