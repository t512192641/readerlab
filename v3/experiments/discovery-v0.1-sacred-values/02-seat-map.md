# 02｜发现席位图

状态：本轮临时阵容；不是长期产品配比、正式透镜名单或生产合同。

## 阵容总览

| 席位 | 来源类型 | 知识家族 | 默认问题 | 与其他席位的差异 |
|---|---|---|---|---|
| S1 | 固定成熟专家 A；复用当前仓库已有框架身份 | 道德心理学／社会价值 | 什么会让一个对象脱离普通交换与讨价还价？改变补偿为什么可能适得其反？ | 关注价值对象、交换边界和反噬条件；不是泛泛解释宗教认同。 |
| S2 | 固定专家组合 B；复用当前仓库已有框架身份 | 社会学／知识社会学 | 一个秩序如何被制度、仪式和合法化机制维持，并在新情境中失效？ | 关注制度化、合法化和秩序维护；与 S1 的价值交换语法不同。 |
| S3 | 轮换单领域专家 | 政治经济学 | 哪些资源、激励、组织约束或分配结构能解释章中的异常或政策分歧？ | 只给一个学科起点，不预指定理论名称。 |
| S4 | 轮换跨领域组合 | 进化生物学 + 组织可靠性/安全工程 | 是否有跨领域的信号、协调、失效或反馈机制，能产生原文没有的新预测？ | 两个领域只是检索起点，不强迫融合；重视可检验条件和失败模式。 |
| S5 | 图书互引／藏书脑 | 书籍中的可迁移框架 | 哪一本真实书中的具体框架能改写本章的分析单位，并生成新分类、诊断或反事实？ | 必须给出具体书、具体知识和改变分析语法的方式；不是主题相似书单。 |

## 席位来源

- S1 的固定框架身份来自 `docs/expert-teaching-v0.1.2-migration-inputs/A/framework.md`，只用于建立发现方向，不把旧 Expert 答案提供给席位。
- S2 的固定框架身份来自 `docs/expert-teaching-v0.1.2-migration-inputs/B/framework.md`，只用于建立不同知识家族的固定方向，不把 B 样本输出提供给席位。
- S3—S5 为本轮临时测试卡；只描述知识库存、常用透镜、默认问题、适用范围和常见盲区，不模拟人物语气。

## 隔离与配额

- S1—S5 与普通基线在独立上下文中运行；每个上下文只接收共同章节、共同任务和自己的席位卡。
- 每个发现脑最多输出 0—2 条轻种子；没有合格方向时必须输出 0 条。
- 五席覆盖至少四个知识家族；任何一个知识家族最多占一个席位，因此没有明显同域集中。
- 最终比较者才能读取全部原始输出；比较者不因理论名、人物名、书名或学科名气加分。
