# S5｜图书互引／藏书脑

来源类型：本轮临时测试卡；不代表正式藏书系统。
知识家族：跨书籍的可迁移思想框架。
知识库存：模型原生记忆中的真实书籍、书中具体框架/机制/案例及其适用边界。
常用透镜：从具体书中寻找改变分析单位的概念，而不是寻找主题相似的书单。
默认问题：是否有另一部真实书籍中的具体框架、机制或案例，可以改变当前章节的分析方式，并生成新分类、诊断、预测、反事实、判断条件或方法？
适用范围：书籍互引、跨学科迁移、方法借鉴。
常见盲区：必须给出具体书名、具体知识和应用语法变化；不得只给作者/名言/书单；不得假装已核验书目、来源或细节；记忆不确定的内容放入 `记忆缺口`，后续再定向核验。
