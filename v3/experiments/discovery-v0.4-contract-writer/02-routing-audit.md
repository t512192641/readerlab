## 3. v0.3 五 Gate 的实际含义

v0.3 不是把“有外部理论”直接变成放行。五 Gate 的顺序和本轮解释如下：

1. **Gate 1：原生问题匹配。** 先确认章节是否给出候选对象、冲突或结果入口，并区分直接匹配、部分匹配和不匹配；直接匹配才可能进入 `CORE/DEEPENING`。[01-gate-v0.3.md](/Users/tianqiang/GitHub/t512192641/readerlab/v3/experiments/discovery-v0.3-gate-calibration/01-gate-v0.3.md:17)
2. **Gate 2：独立分析语法。** 删除理论名、人名和标签后，仍要能写成“解释对象 → 变量 → 动作或比较 → 可观察结果 → 边界／替代解释”。[01-gate-v0.3.md](/Users/tianqiang/GitHub/t512192641/readerlab/v3/experiments/discovery-v0.3-gate-calibration/01-gate-v0.3.md:33)
3. **Gate 3：作者等价测试。** 新增中间条件或边界只能成为 `DEEPENING`；只有改变判断对象或解释动作、形成非作者等价的新结果，才可能成为 `CORE`。[01-gate-v0.3.md](/Users/tianqiang/GitHub/t512192641/readerlab/v3/experiments/discovery-v0.3-gate-calibration/01-gate-v0.3.md:41)
4. **Gate 4：L1/L2/L3 主张强度。** `L2` 允许条件机制和反事实，但必须标出未观察的变量、行为、时序和对照；`L3` 才需要决定性变化、结果、时间顺序、比较／反事实及替代解释区分。本轮没有任何候选达到 L3。[01-gate-v0.3.md](/Users/tianqiang/GitHub/t512192641/readerlab/v3/experiments/discovery-v0.3-gate-calibration/01-gate-v0.3.md:51)
5. **Gate 5：产品新增结果。** 新增结果必须是诊断分类、条件预测、反事实、观察清单或迁移边界；通过 Gate 5 只证明读者多了一个受限动作，不等于产品接受。[01-gate-v0.3.md](/Users/tianqiang/GitHub/t512192641/readerlab/v3/experiments/discovery-v0.3-gate-calibration/01-gate-v0.3.md:80)

因此，`CORE` 的定义是“达到 L2 的非作者等价受限核心机制主张”，不是个案证明；`DEEPENING` 是有产品新增但主要深化作者轨道；`HOLD` 是有保留价值但只能 L1 或缺少 L2 承载。[01-gate-v0.3.md](/Users/tianqiang/GitHub/t512192641/readerlab/v3/experiments/discovery-v0.3-gate-calibration/01-gate-v0.3.md:92)

### 5.2 C5 的本轮收紧

- **结果层收紧：** 必须分开承诺、行动、制度和可测量结果；签署、立法或表态不得直接算作结果。
