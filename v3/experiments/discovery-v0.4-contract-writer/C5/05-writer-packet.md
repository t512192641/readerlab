# C5 Writer Packet

> 这是给 Writer 的最小控制输入，不是 Reader 成品。Writer 只使用本包中的四部分内容，不自行补充材料。

## 1. Writer-ready source context

以下是第 8 章中本篇真正需要的固定原文事实：

- 全球变暖、核战争、生态崩溃和科技颠覆等问题，必须从全球角度处理，不能只按单一国家或地方的尺度处理。
- 宗教与民族主义可能把人拉回地方阵营，使人优先考虑自己的国家利益，从而与全球问题所要求的跨境协作形成张力。
- 原文同时保留一个重要例外：有些宗教人士拒绝狭隘民族主义，抱持更普遍的愿景。因此，不能把宗教身份直接写成合作失败的唯一原因。

本节只提供固定原文的观察上下文；全球公共品机制、成本分配、监督和履约不是上述原文事实的自动延伸。

## 2. C5 contract 摘要：Writer 必须遵守的语义约束

- 框架处理的是全球公共品与集体行动难题：行动产生跨境外溢，收益可能非排他、非竞争，各方贡献以不同方式聚合；共同受益不保证共同投入。
- Writer 必须把 `value / distribution / execution` 分开又连起来：目标和责任是否被共同认可；成本、收益和风险如何分配；承诺如何被监督、约束并转化为履约结果。三分是 ReaderLab 教学整理，不是外部作者正式命名的固定分类。
- 必须解释一般机制：当成本集中、收益分散或延后，未出力者仍能受益时，会出现 `free riding`；共同价值不会自动生成公平分摊、监测制度、违约后果或可信 `fulfillment`。
- 应持续追问：谁承担当期成本和风险，谁受益，谁可以搭便车，谁有否决权，是否有分摊、补偿、监督和可信履约安排。
- 必须把 `commitment`、`action`、`result` 分开：签署、表态或承诺不等于实际行动，实际行动也不等于可测量结果。
- 当前原文应用只能写一般机制、条件判断和受限反事实：可使用 L1 的框架说明与一般机制，或 L2 的“若……则可能……”推论；不得升为 L3 的具体个案因果、时序或已证结论。
- 必须同时保留身份、利益和制度执行三种竞争解释。身份可能改变责任边界、关怀对象或付费意愿，但不能被预设为唯一阻断机制。
- 必须区分 `source identity` 与 `external structure`：固定原文只提供本包列出的章节上下文；全球公共品与集体行动是外部分析结构；当前应用所得结论是受限推论，不能把其中一层冒充另一层。

## 3. Structured asset：Writer 需要的字段摘要

### framework

全球公共品与集体行动分析：用跨境外溢、公共品属性、贡献聚合、搭便车、分配和执行机制，解释为什么共同认可仍可能不足以带来充分合作。

### native problem

许多参与者共同受益，但单方承担可见而集中的成本；收益向多个地区扩散、可能延后，未贡献者仍可受益。由此要检查价值是否一致、负担如何分配、承诺能否变成履约结果。

### key variables

跨境外溢；收益是否非排他、非竞争；贡献是相加、受最弱环节限制，还是依赖关键少数；影响范围；价值边界；成本、收益与风险；搭便车空间；否决权；分摊与补偿；监测数据；违约后果；`commitment / action / result`。

### mechanism

成本集中而收益分散或延后，会制造少贡献诱因；公共品的重要性本身不能消除这种诱因。`value` 影响共同目标与责任范围，`distribution` 影响谁愿意承担，`execution` 决定承诺能否被核验、违约是否有后果并形成可信履约。三者相互影响，不能写成彼此隔离的口号。

### usage

先确认外溢、收益属性、贡献聚合和影响范围；再检查 `value`、`distribution`、`execution`；列出谁承担、谁受益、谁搭便车、谁否决；分开记录承诺、行动和结果；最后比较身份、利益、制度执行三种解释，并用条件反事实检查：加入可执行的分摊、监测和履约后，身份是否仍是唯一阻断因素。

### cognitive turn / new result

不要停留在“宗教或民族身份阻碍全球合作”的单一诊断。更精确的受限判断是：若收益跨境分散且难以排除未贡献者、成本集中、搭便车空间较大，同时缺少可执行的分摊、监测和履约，那么即使存在共同普世价值，政策也可能继续地方化或合作不足；若这些机制被建立，身份就不再自动构成唯一阻断因素，但仍须检查利益和制度执行。

### claim limit

上述是一般机制与受限反事实，不是本章已观察到的具体国家冲突、特定成本分布、搭便车事实、补偿效果、制裁效果或履约结果。缺少的成本、收益、时序、补偿反应和结果证据保持未知；不能把某一模型处方写成通用答案。

### transfer

迁移到气候、传染病监测、海洋塑料、金融稳定或世界和平等议题时，先重新确认：是否有跨境外溢；未出力者能否被排除；一方受益是否挤占另一方；贡献如何聚合；谁承担、谁受益、谁否决以及如何分摊、补偿、监督；看到的是承诺、行动还是可测量结果。不能只因议题是“国际问题”就套用框架。

### teaching-example boundary

三镇水库是独立的低背景教学案例，不是第 8 章事实，也不是当前案例的证据。正文可以不用它；若使用，必须明确它是另设的教学例子，不能伪装成章内事实或外部来源案例。

## 4. Writer must preserve

- `value / distribution / execution` 的区分及其相互作用。
- 成本集中、收益分散或延后的结构，以及由此产生的 `free riding`。
- `fulfillment`：分摊、监督、违约后果和可信履约不能被共同价值取代。
- 谁承担、谁受益、谁否决，及补偿／分摊安排的检查。
- `commitment / action / result` 的三层证据区分。
- `source identity` 与 `external structure` 的区分：固定原文、外部分析结构、教学整理和当前受限推论不能互相冒充。
- 身份、利益、制度执行的竞争解释，不能把身份写成唯一原因。
- L1 的一般机制与 L2 的条件句、受限反事实；不越过允许的主张上限。
- 未来迁移检查：先核对外溢、收益属性、贡献方式、承担者／受益者／否决者和证据层级。

## 5. Writer must not

- 把当前案例写成具体国家之间已经发生或已被证明的冲突。
- 把三镇教学案例伪装成第 8 章的事实，或把它写成当前案例证据。
- 把签署、表态或承诺写成行动或结果；把行动写成结果。
- 把身份、宗教或民族主义写成唯一因果解释；不得删掉利益和制度执行解释。
- 补写当前案例缺失的成本、收益、时间序列、补偿反应、制裁效果或履约结果。
- 把 `value / distribution / execution`、三镇案例或迁移问题写成外部作者正式命名，或把外部结构倒写成固定原文事实。
- 升到 L3，写具体个案因果、普遍处方、产品接受判断或任何内部术语。
- 输出研究历史、来源审计、分类说明、合同解释、备选稿或内部报告。

## 6. Expected output brief

只生成一个面向正常成人读者的中文 `reader_text`，600–1000 个中文字符；不要求读者查资料。正文必须自然回答：

1. 这套全球公共品与集体行动框架解决什么问题；
2. 它与“宗教／民族认同把人分成地方阵营”的表面阅读有什么不同；
3. 它带来的新判断是什么，尤其是价值、分配和执行如何共同影响合作；
4. 这个判断只在什么条件下成立、哪些事实不能据此声称已经发生；
5. 离开当前章节后，读者如何把它迁移到另一个跨境议题。

正文不得出现候选 ID、角色名、任务名、schema、审计、研究历史、内部分类、`source identity`、`external structure`、L1/L2/L3 等控制词；也不要写 Writer、contract 或 packet。可以使用自然中文表达“来源不同”“这只是条件判断”“承诺不等于结果”等边界。

```text

```
