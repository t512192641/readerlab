# C5 结构化知识资产

> 用途：供 Writer 取用的结构化知识资产；最高主张级别为 L2。不是读者文章，不是 Writer packet。

## 1. framework name

- **全球公共品与集体行动分析**（Global Public Goods and Collective Action）。
- 框架范围：分析跨境外溢、公共品属性、贡献聚合、搭便车，以及分配与执行机制；不把所有国际冲突都归结为经济利益。

## 2. one-sentence use

用来判断：当许多参与者共同受益、单方承担集中成本且未贡献者仍可受益时，价值是否一致、负担如何分配、承诺能否被监督并转化为履约结果，以及身份、利益和制度执行哪一种或哪些机制仍在起作用。

## 3. native problem

- **基本情形**：行动会产生跨境外溢；收益具有非排他性和非竞争性；各方贡献以相加、最弱环节限制或关键少数贡献等方式聚合。
- **结构性难题**：单方当期成本通常集中、可见，收益却跨境分散、可能延后；未出力者仍能受益，于是产生 free riding（搭便车）诱因，共同投入可能低于所需水平。
- **必须追踪**：谁承担成本和风险、谁获得收益、谁可以搭便车、谁有否决权；是否有公平或可执行的分摊、补偿、监督和 fulfillment（履约）安排。
- **核心提醒**：共同认可或普世价值不会自动生成费用公式、监测制度、违约后果或可信履约。

## 4. key variables

| 变量组 | 要记录的变量 |
|---|---|
| 公共品属性 | 跨境外溢、收益非排他性、收益非竞争性、贡献聚合方式、影响范围 |
| 价值 | 是否追求同一结果；责任边界如何定义；身份/信仰如何影响纳入谁、关心谁 |
| 分配 | 谁先行动、谁多付钱、谁承担转型成本与风险、谁受益、是否补偿、分摊依据是什么 |
| 执行 | 谁监督、用什么数据核验、是否公开、违约后果是什么、是否存在可信 fulfillment |
| 行动者位置 | 身份、利益、责任主张、否决权、可退出性、搭便车空间 |
| 证据状态 | commitment（承诺/表态）、action（制度或实际行动）、result（可测量结果） |
| 教学组织 | **value / distribution / execution** 三分；这是 ReaderLab 教学整理，不是外部作者正式命名的固定三分法 |

## 5. mechanism

1. 跨境外溢与非排他、非竞争收益，使单一行动者难以独占收益或排除未贡献者；贡献聚合方式决定单方投入能否替代他方投入。
2. 当成本集中而收益分散、延后或跨境扩散时，参与者可能等待他人承担成本，形成 free riding；“事情重要”不足以消除少贡献诱因。
3. 按 ReaderLab 的教学整理，先区分 **value**（目标与责任是否被共同认可）、**distribution**（谁承担、谁受益、谁补偿谁）和 **execution**（怎样监督、约束并完成履约）。三者相互影响，不是三个互不相干的盒子。
4. 价值语言可能扩大或缩小“我们”的责任边界；利益结构影响成本与收益选择；制度执行决定承诺是否能被核验、违约是否有后果。身份、利益和制度执行是竞争解释，不预设身份是唯一阻断因素。
5. 必须把 commitment、action、result 分开：表态或签署不等于实际行动，实际行动也不等于已产生可测量结果。
6. 反事实检查：若加入可执行的成本分摊、监测和 fulfillment，身份是否仍是唯一阻断因素？该检查用于识别机制，不把反事实写成 current case 已发生的事实。

## 6. usage steps

1. **确认适用性**：标出边界外溢、收益是否非排他/非竞争、贡献如何聚合、影响范围多大。
2. **查 value**：各方是否认可同一目标；身份或信仰是否改变责任边界、牺牲意愿或正当性判断。
3. **查 distribution**：列出谁承担当期成本和风险、谁获得收益、谁可搭便车、谁有否决权；检查分摊公式、补偿与公平争议。
4. **查 execution**：列出监测主体、数据、公开方式、违约后果、激励/制裁和可信 fulfillment；不要把特定模型处方当通用答案。
5. **查贡献聚合与 free riding**：判断“所有投入相加”“最弱环节”或“关键少数”哪一种结构在起作用。
6. **分开编码证据**：分别记录 commitment、action、result；缺少后两者时，不得把承诺升级为结果。
7. **做竞争解释和反事实**：同时保留身份、利益、制度执行；问加入可执行分摊、监督和履约后，阻断是否仍存在，以及阻断是否仍只能归因于身份。
8. **锁定主张级别**：回到 current case 时只输出条件化分析；缺失的成本、收益、时序、补偿反应或履约结果保持 unknown。

## 7. cognitive turn

- 从“宗教/民族身份阻碍全球合作”的单一身份诊断，转为“**value—distribution—execution** 的受限结构诊断”。
- 从“大家都说重要”转向检查：谁承担集中成本、谁获得分散收益、谁可以搭便车、谁能否决、如何分摊、如何监督、如何 fulfillment。
- 这不是取消身份解释：身份仍可能影响责任范围与付费意愿；只是必须与利益结构和制度执行机制并列检验。

## 8. allowed L1

- 说明框架定义：跨境外溢、收益非排他性/非竞争性、贡献聚合方式、影响范围、搭便车和公共品供给难题。
- 说明一般机制：成本集中而收益分散会制造少贡献诱因；共同价值不能自动解决分配、监督和履约。
- 复述固定原文层已提供的区分：技术问题、政策问题、身份认同问题；全球变暖、核战争等问题需要跨境视角；宗教/民族认同可能把责任边界地方化，同时固定原文保留拒绝狭隘民族主义的例外。
- 复述有来源映射的研究提醒：特定模型中的激励/制裁与联盟稳定；特定研究中政策承诺与实际结果需并列检查；不得超出各自研究边界。
- 明确 value / distribution / execution、三镇水库和六问是 ReaderLab 教学整理或教学案例，不冒充外部作者原名。

## 9. allowed L2

- 可以提出条件判断：**若**收益跨境分散且非排他/非竞争、成本集中、free riding 空间较大，**且**缺少分摊、监督和 fulfillment，**则**即使存在共同普世价值，政策也可能继续民族化或合作不足。
- 可以提出受限反事实：**若**加入可执行的成本分摊、监测与履约机制，身份就不再自动构成唯一阻断因素；仍需检查利益与制度执行。
- 可以把固定原文的身份论述与外部公共品结构并置，形成 current application inference；必须使用“可能、若、可检验、不能排除”等条件化表达。
- 可以迁移到气候、传染病监测、海洋塑料、金融稳定或世界和平等候选议题，但每次都要重新确认公共品属性与贡献方式。

## 10. prohibited L3

- 不得把 current case 写成某个具体国家冲突，或声称本章已观察到特定国家的 free riding、成本分布、分配不公、补偿效果、制裁效果或履约结果。
- 不得声称宗教或民族主义已经单独造成某国合作失败；不得把身份当作唯一因果解释。
- 不得把签署、立法、表态直接写成 action 或 result；不得把 action 直接写成 result。
- 不得把诺德豪斯的特定模型中的激励/制裁处方写成所有合作问题的通用答案。
- 不得把“value / distribution / execution”三分、三镇案例或六问清单伪装成外部作者正式命名或原文事实。
- 不得补写缺失的成本、收益、时间序列、补偿反应或 fulfillment evidence；不得升到 L3 的个案因果、时间序列或已证结论。

## 11. independent low-background example

**三镇水库（仅作框架教学，不移植为 current case 事实）**

| 检查项 | 教学设定 |
|---|---|
| 场景 | 三座小镇共同依赖一座上游水库；清理污染物每镇每年约一百万元 |
| 外溢与收益 | 水库变干净后，三镇居民都受益；难以只让付款者享受安全水质，收益具有跨镇扩散性 |
| value | 三镇是否都把安全饮水视为共同目标 |
| distribution | 按人口、污染量、支付能力或受益程度分摊；谁承担成本、谁承担风险、是否补偿 |
| free riding | 丙镇认为甲乙完成大部分清理后自己也能受益，选择观望 |
| execution | 谁检测排污、如何公开水质数据、拖欠费用有什么后果 |
| commitment/action/result | 联合声明只是 commitment；出资和清理是 action；水质数据改善才是可测量 result |
| 框架教学点 | 共同价值不能替代费用公式、独立监测和可信 fulfillment；只有惩罚也不能自动解决分配不公 |

## 12. transfer

迁移到新议题时，按以下六问重新核验，不因“国际问题”四字自动套用：

1. 结果或损害是否跨出行动者边界，形成跨境外溢？
2. 未出力者能否被排除在收益之外？
3. 一方受益是否会挤掉另一方同类收益？
4. 贡献是相加、受最弱者限制，还是由少数关键贡献决定？
5. 成本、收益和风险由谁承担，谁受益，谁有否决权，是否有分摊/补偿/监督安排？
6. 现有证据是 commitment、action 还是可测量 result；如何验证 fulfillment？

可作为后续检查对象的议题包括气候、传染病监测、海洋塑料、金融稳定和世界和平；这些只是迁移候选，不是 C5 current case 的事实或证据。

## 13. boundary

- **source identity vs external structure**：固定原文（C5-TEXT）提供技术/政策/身份认同区分，以及宗教与民族身份、全球问题和地方忠诚之间的张力；全球公共品与集体行动分析（C5-S1 至 C5-S3）提供跨境外溢、公共品属性、free riding、分配和执行的外部结构。前者不自动包含后者的完整机制，后者也不替固定原文给出唯一解释。
- “value / distribution / execution”是 ReaderLab 的教学整理；三镇案例和六问是 ReaderLab 教学工具，不是外部作者正式命名的方法或 current case 证据。
- 身份、利益和制度执行必须作为竞争解释保留；身份可能影响责任边界和牺牲意愿，但不因此成为唯一原因。
- commitment、action、result 是不同证据层；承诺不等于行动，行动不等于结果。
- 诺德豪斯的激励/制裁结论受特定模型与研究边界约束；Bättig 与 Bernauer 的承诺/结果提醒受特定时期和数据范围约束。
- current application 只能写 L1/L2 的条件判断和反事实检查；不能把 current case 写成某个具体国家冲突，不能升 L3。
- 任何需要补写 current case 缺失事实、或把身份写成唯一因果、把承诺写成结果的版本，立即停止。
