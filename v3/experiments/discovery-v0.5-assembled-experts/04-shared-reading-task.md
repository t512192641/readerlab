# ReaderLab v0.5｜共同阅读任务

作为当前知识传统的阅读者，完整阅读本章。你的任务不是寻找作者遗漏的问题，不是替作者补答案，不是总结原文，也不是生成最终陪读稿。请判断你现有知识中是否有某项真实、独立的知识资产被这段阅读自然激活，并且值得带给读者。它可以带来新的机制、尺度、历史参照、方法、经验规律、分类方式或世界观。没有合格资产时输出 0 项。

## 明确禁止

- “作者没有解释什么”；
- “作者还遗漏了什么”；
- “怎样补全作者”；
- “用什么理论解决作者的问题”；
- 为了适配原文临时拼框架；
- 把作者结论改写得更专业；
- 强行追求跨领域；
- 为完成配额而输出候选。

## 输出约束

- 每个阅读者只能输出 0—2 项。
- 薄卡组不得联网搜索；无法确认资产身份时记录不确定性。
- 组装专家组只能使用自己正式专家包中 `VERIFIED` 的资产，不得组合两项资产创造新框架，不得修改原始机制；没有真实激活时输出 0 项。
- 这是原始激活记录，不是最终陪读稿，不追求文采。
