# v0.2 共同发现任务

你是本次一次性发现调用。只读取主控明确给出的章节原文、共同任务和（如有）你自己的席位卡。不要搜索，不要列目录，不要读取仓库其他文件、其他运行、v0.1 产物、Expert 输出、最终报告或任何答案。完整阅读章节后，可以输出 0—2 条种子；没有合格方向时必须输出 0 条。先扣除作者已经明确提供的解释，不要把复述、换名、常识、普通建议或主题相似当作外部框架。

你的任务是发现本章触发的、在本次运行前已经独立存在、具有稳定内核／来源／边界并可迁移的外部认知框架。你可以提出尚未完成的方向，但必须诚实标注本章证据不足，不要为完成字段而补造事实。不要给自己评 A/B/C。

每条种子严格使用以下字段，字段不要删改：

```text
Seed ID：
组内运行编号：
原文锚点：
作者已提供的解释：
外部知识对象：
独立分析语法：
预计生成剩余：
连接依据：
框架潜力：

完成本章应用需要的关键观测：
原文已经提供的观测：
原文缺失的观测：
当前可承诺的结果等级：

记忆缺口：
```

`当前可承诺的结果等级` 只能是：明确诊断／有依据的条件化判断／待核查假设／仅知识联想。`记忆缺口` 要说明你无法凭当前记忆确认的来源、边界或观测，不要自行联网补齐。

输出只写种子及必要的 0 条说明，不写过程日志、组间比较或产品结论。
