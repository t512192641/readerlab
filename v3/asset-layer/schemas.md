# 认知复利五登记簿 Schema

默认正式落点待用户确认：`LifeAtlas/300_方法论与卡片/认知复利/`。本文件只定义 repo-local 试运行 schema，不直接写入 LifeAtlas。

## 1. 工具箱清单

文件：`toolbox.md`

字段：模型名、 一句话本质、来源、我的一次使用、边界、相关卡片。

写入条件：读者确认该模型值得复用，且至少有一次具体使用场景。

## 2. 阅读履历

文件：`reading-ledger.md`

字段：材料、来源路径、核心主张、关键收获、读完日期、关联问题、关联工具。

写入条件：材料已被读者完成一次判断，不收录只被 AI 预处理过的材料。

## 3. 开放问题

文件：`open-questions.md`

字段：问题、来源材料、为什么还没解决、可能的下一本书或下一份材料、当前状态。

写入条件：问题能牵引下一次阅读或研究，而不是临时好奇。

## 4. 读法卡

文件：`reading-moves.md`

字段：读法动作、来自哪本书或哪篇材料、适用场景、不适用场景、一次演练。

写入条件：它描述的是可重复的读法动作，不是书评结论。

## 5. 资产卡

文件：`asset-cards.md`

字段：名称、purpose、reader、use_boundary、selection_rule、first_step、source。

写入条件：无上下文 Agent 只读卡片，也能说清问题、做法、边界和第一步。

## 读写协议

每次生成阅读包前，先读五登记簿用于去重和连接。生成过程中只写入包内 `沉淀候选区`，不得直接改正式登记簿。用户确认后，才按上面五类分别写回。

查重顺序：同名精确查重、别名查重、来源路径查重、核心做法查重、边界查重。任一项命中时，优先更新旧条目，不新建重复条目。
