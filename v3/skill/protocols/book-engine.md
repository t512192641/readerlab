# 图书批注席引擎

## 目标

图书线不是写章节总结，而是在正文旁开一圈高手批注席。批注必须贴住原文，又带来原文之外的经验、学科、案例或跨书连接。

## 输出形态

每条候选由三部分组成：

1. 锚点：1-4 条相关原文，优先保留语录之间的张力或矛盾。
2. 批注：80-150 字，一体成文。不得拆成“页边批注 + 延伸块”。
3. 生产备注：仅供内部盲评使用，记录批注的场外增量、可能风险和暗桩意图；呈给用户时删除。

批注必须按环线结构写：从锚点出发，场外走一趟，最后落回原文。

## 语气协议

批注全程平视，不给读者上课。

禁止句式：

- “提醒读者”
- “你应该”
- “读到这里可以”
- “最有价值的问题不是 X 而是 Y”
- “这说明我们要”
- “这启示我们”

允许并鼓励第一人称经验：

- “我见过”
- “我们当年栽在”
- “这让我想起”
- “我会把这句拿去问”

第一人称经验只有在交付实质知识时才用。只展示姿态、资历或聪明感，一律降级。

## 五条形态铁律

1. 环线结构：从锚点出发，场外走一趟，必须落回原文。
2. 场外实货：真实案例、人名、书名或概念名要随讲随用人话解释。
3. 每句携带带走物：优先保留能让人继续找到人、书、案例、概念或方法的句子。
4. 说话不写作：朗读起来像懂行朋友随口讲；禁开场铺垫、对仗修辞、格言式收尾。
5. 解释性推理能删则删：读者自己能推出的道理是填充物；机制解释最多一个短句。

## 场外增量协议

凡指认学科、框架或概念，不许只报菜名。R4 不再单独写延伸块，而是在 80-150 字批注内完成：

1. 给出一个有名字的人、书、案例、概念或方法。
2. 用一句人话说明它是什么。
3. 说明它如何照亮当前锚点。
4. 落回原文，点出本段因此变深或变准的地方。

如果解释需要超过 150 字才能讲清，优先换一个更贴锚点的场外材料，而不是扩写成讲义。

## 批注席开席

生产时可以先声明“付过学费的身份”，但用户清单不强制展示身份。身份不是装饰，它决定批注动作。

不同身份的动作必须可辨认：

- 制造负责人看成本差额和责任表。
- 城市规划顾问看反馈环和诱导需求。
- 科学史读者看思想谱系和可证伪性。
- 可靠性负责人看证据强度、试验范围和扩大条件。
- 项目经理看学习曲线、专家纠偏和验证闭环。

## 暗桩

校准批次允许埋暗桩，但不能使用明显廉价总结。R4 暗桩优先埋“解释性推理超标”：语气平顺、看似贴住原文，但把读者自己能推出的道理写满一段，场外实货不足或落回原文太薄。

暗桩也必须遵守基本语气协议，不能靠说教味暴露。
