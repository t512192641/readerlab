# 图书批注席引擎

## 目标

图书线不是写章节总结，而是在正文旁开一圈高手批注席。批注必须贴住原文，又带来原文之外的经验、学科、案例或跨书连接。

R6 产品铁律：可见即精选。低于 `有用` 的批注不得出现在读者页；宁交活点清单，不交平庸批注。惊艳密度随模型档位、素材新鲜度和外部知识厚度变化，不作为硬保证。

## 输出形态

读者页只出现存活批注，或在 0 条存活时出现活点清单。生产过程中的素材卡、候选池、自检记录和比较记录进入 audit，不进入读者页。

上页批注由两部分组成：

1. 锚点：1-4 条相关原文，优先保留语录之间的张力或矛盾。
2. 批注：80-150 字，一体成文，从锚点出发，场外走一趟，最后落回原文。

0 条存活时交付活点清单：

1. 锚点原文。
2. 为什么值得批。
3. 素材线索：人、书、案例、概念或方法入口。

## 1. 选材 Pass

先识别活点，再选场外素材。不要先写批注。

活点包括：

- 原文中有明显张力、反常识、代价、边界、失败风险或方法入口。
- 原文只露出一个词、一句判断或一个动作，但背后有完整学科、案例、人物、书或方法。
- 原文和另一个章节、另一本书、一个真实案例之间存在可解释的对账关系。

每个锚点必须准备 5-7 路候选方向，方向要来自不同学科或付过学费的身份。每个锚点至少有一件非第一联想素材。非第一联想指不是本段关键词直接喊出的常见材料，而是能从远一点的位置照亮原文的事实、人物、书或方法。

每个候选场外素材必须先立素材卡。素材卡写入 audit，禁止进入读者页。

```text
anchor:
route_identity:
outside_material:
known_facts:
  - 具体事实 1
  - 具体事实 2
  - 具体事实 3（可选）
connection_to_anchor:
use_boundary:
source_confidence: high | medium | low
first_association: yes | no
decision: use | reject
```

素材卡规则：

- 写不出 2-3 个确实知道的具体事实，素材禁用。
- 连接必须具体说明它怎样照亮锚点，不能只写可类比、相似。
- 每个锚点至少保留一件 `first_association: no` 的素材进入候选池。
- 不确定的外部材料换掉，不能靠肯定语气补。

## 2. 成文 Pass

每个锚点生成 5-7 条候选批注。不同候选必须使用不同学科或身份出发，单条候选单独生成调用。候选只能使用通过素材卡的场外素材，不允许临场编新素材。

生成提示必须内嵌 `v3/skill/examples/book-annotation-examples.md` 中的：

- 2 条金标正例。
- 3 条典型反例。
- 每条反例对应的用户原话判词。

成文约束：

- 不写“本段说明”“提醒读者”“你应该”“读到这里可以”“这启示我们”。
- 不写开场铺垫、对仗修辞、格言式收尾。
- 外文术语必须配中文释义。
- 人名必须配身份短语。
- 概念必须随讲随用，不允许只报名字。
- 第一人称只在能交付实质知识时使用，不能用资历替代知识。

## 3. 自检 Pass

每条候选过二元清单。命中任何一条，必须定点修复后复检；不能用整体感觉放行。

| 自检项 | 命中处理 |
| --- | --- |
| 外文无中文释义？ | 加一句短释义，或换中文可讲清的素材。 |
| 人名无身份短语？ | 加身份短语，例如“心理学家 Gary Klein”。 |
| 协议词或模板语泄漏进正文？ | 删除 `锚点`、`场外素材`、`环线结构`、`读者收益` 等生产词。 |
| 概念在工具箱已存在且未深化？ | 换新素材，或补一个此前没讲透的事实、案例、边界。 |
| 案例无出口？ | 补人名、书名、案例名、方法名或可追索入口。 |
| 与原文字面重复？ | 删除重复解释，改写为外部事实如何改变原文读法。 |
| 解释性推理超标？ | 删除读者自己能推出的道理，只留一个短机制句。 |
| 没有落回原文？ | 最后一句必须回到锚点动作、判断或边界。 |

## 4. 裁判 Pass

R6 使用死刑制，不再选“相对最好”的 60 分批注。

1. 先查即死项。命中即死项，修复后仍命中就淘汰。
2. 再做金标比较：候选逐条与金标正例比较，问题只有一个：这条是否不输金标？
3. 不能证明不输金标的候选淘汰；理由写入 audit。
4. 同一锚点可存活多条，也可存活 0 条。
5. 全批次存活 0 条时，读者页交付活点清单，并明确没有合格批注。

## 禁止项

- 用高级词换皮原文。
- 把场内展开包装成批注。
- 用例子解释例子，但不交付新认识。
- 只报模型名、人名、书名，不解释其用法。
- 为了凑条数放出低于 `有用` 的内容。
- 把 audit、素材卡、暗桩、盲评或裁判术语写进读者页。
