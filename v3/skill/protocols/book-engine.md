# 图书批注席引擎

## 目标

图书线不是写章节总结，而是在正文旁开一圈高手批注席。批注必须贴住原文，又带来原文之外的经验、学科、案例或跨书连接。

产品目标不是让中档模型稳定写出“惊艳”，而是把即死项压到零，并把“有用”做成地板。惊艳密度随模型档位、素材新鲜度和外部知识厚度提升，不作为本 Skill 的硬保证。

## 输出形态

读者页只出现最终胜出的批注。生产过程中的素材卡、候选池、自检记录和比较记录进入 audit，不进入读者页。

每条上页批注由两部分组成：

1. 锚点：1-4 条相关原文，优先保留语录之间的张力或矛盾。
2. 批注：80-150 字，一体成文，从锚点出发，场外走一趟，最后落回原文。

## 三段式生产结构

### 1. 选材 pass

先识别活点，再选场外素材。不要先写批注。

活点包括：

- 原文中有明显张力、反常识、代价、边界、失败风险或方法入口。
- 原文只露出一个词、一句判断或一个动作，但背后有完整学科、案例、人物、书或方法。
- 原文和另一个章节、另一本书、一个真实案例之间存在可解释的对账关系。

每个候选场外素材必须先立“素材卡”。素材卡写入 audit，禁止进入读者页。素材卡最低字段：

```text
anchor:
outside_material:
known_facts:
  - 具体事实 1
  - 具体事实 2
  - 具体事实 3（可选）
connection_to_anchor:
use_boundary:
source_confidence: high | medium | low
decision: use | reject
```

素材卡规则：

- 写不出 2-3 个确实知道的具体事实，素材禁用。
- 只能写“确实知道”的事实；不确定的外部材料要换掉，不能靠语气补。
- 连接必须具体说明“它怎样照亮锚点”，不能只写“可类比”“相似”。
- 素材卡可以收录 rejected 素材，供后续排错，但 rejected 素材不得进入候选批注。

### 2. 成文 pass

每个锚点生成 2-3 条候选批注。候选必须使用已通过素材卡的场外素材，不允许临场编新素材。

生成 prompt 必须内嵌 `v3/skill/examples/book-annotation-examples.md` 中的：

- 2 条金标正例。
- 3 条典型反例。
- 每条反例对应的用户原话判词。

成文约束：

- 不写“本段说明”“提醒读者”“你应该”“读到这里可以”“这启示我们”。
- 不写开场铺垫、对仗修辞、格言式收尾。
- 外文术语必须配中文释义。
- 人名必须配身份短语。
- 概念必须随讲随用，不允许只报名字。
- 第一人称只在能交付实质知识时使用；不能用资历替代知识。

### 3. 自检 pass

每条候选过二元清单。命中任何一条，必须定点修复后复检；不能用整体感觉放行。

| 自检项 | 命中处理 |
| --- | --- |
| 外文无中文释义？ | 加一句短释义，或换中文可讲清的素材。 |
| 人名无身份短语？ | 加身份短语，例如“心理学家 Gary Klein”。 |
| 协议词 / 模板语泄漏进正文？ | 删除 `锚点`、`场外素材`、`环线结构`、`读者收益` 等生产词。 |
| 概念在工具箱已存在且未深化？ | 换新素材，或补一个此前没讲透的事实、案例、边界。 |
| 案例无出口？ | 补人名、书名、案例名、方法名或可追索入口。 |
| 与原文字面重复？ | 删除重复解释，改写为外部事实如何改变原文读法。 |
| 解释性推理超标？ | 删除读者自己能推出的道理，只留一个短机制句。 |
| 没有落回原文？ | 最后一句必须回到锚点动作、判断或边界。 |

## 裁判：成对比较制

候选不再用绝对分数裁判。每个锚点的 2-3 条候选进入小型锦标赛：

1. 候选两两比较金标：哪一条更像范例库里的金标？
2. 比较时只问四件事：是否有确实外部事实、是否说人话、是否落回原文、是否避开已知反例失败类型。
3. 胜者上页；败者和败因进入 audit。
4. 如果所有候选都不如典型反例，整组退回选材 pass，不强行上页。

## 暗桩

校准批次允许埋暗桩，但不能使用明显廉价总结。R5 暗桩优先埋“通过三段式大部分检查、但与金标相比仍显著更弱”的候选，例如：

- 素材卡事实是真的，但连接只停在表层。
- 批注有外部素材，但没有把原文读法改变。
- 批注语气顺，但案例出口弱或落回原文薄。

暗桩也必须遵守基本语气协议，不能靠说教味暴露。
