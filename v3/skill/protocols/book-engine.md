# 图书线协议

## 目标与边界

图书线先交付可信正文，再只把真正改变读法的完整认知放到正文附近。它不写章节摘要，不用 AI 替代原文，也不为填满页面制造批注。可见内容允许为 0；候选数量和相对排名都不能形成交付配额。

- 图书与长文保留完整正文，只做空格、空行、断行等轻量清理；任何移动或删除都必须能由 source map 追溯。
- 生产记录、候选、事实核查和裁判理由进入 audit，不进入读者页。
- 读者页只保留正文和通过绝对裁判、事实核查与冷读的完整认知。
- 一个可见单元只改变一种原文读法；多个事实可以共同支撑这一判断，但不能并列制造第二主题。

## 输入

1. 登记的原始材料与本章范围。
2. 正文整理结果及逐段 source map。
3. 本次 run manifest 允许的外部来源和输出目录。
4. `v3/standards/book-annotation-rubric.md`。

正文或 source map 不完整时停止，不进入认知生产。

## 执行链

### 1. 正文与来源地图

正文整理者先恢复本章一手主体，并在 audit 中逐段记录来源位置、保留、移动和删除。读者页在任何 AI 陪读之前以正文为主；旧 AI 块不得混入正文。

### 2. 两个独立锚点提名

两个提名 Agent 分别只看正文、source map 和自己的短合同，互不读取对方结果。每个提名都须给出原文定位、此处容易被怎样读浅或读偏、值得进一步调查的问题；可以提名 0 个或多个锚点，不得为了覆盖章节凑数。

### 3. 归并锚点

归并者按“是否在解决同一个认知问题”合并重复或互补提名，并保留有独立价值的少数意见。归并不是多数表决：两人都提名不自动通过，只有一人提名也不自动淘汰。输出是带原文落点和认知问题的锚点集合；没有承重锚点时可以为空。

### 4. 三个 Agent 批量提交完整认知

三个认知 Agent 各自接收整批归并锚点，独立提交完整候选，而不是按固定学科、身份或素材路线分工。每条候选必须一次交齐：

- 唯一判断；
- 要纠正或深化的默认理解；
- 少量必要事实及可定位来源；
- 它怎样具体改变这段原文的读法；
- 必要边界，以及不应展开的枝节。

人名、书名、案例、模型或事实片段只能作证据，不能单独参赛。Agent 可以对任一锚点不提交，不能用固定篇幅或固定数量补齐批次。

### 5. 事实核查

三个候选 Agent 各自用类型化 request 列全必要证据中的源内事实、外部事实与因果断言；request / claim id 非空且唯一。单实例 0 候选明确为 `not-applicable`；至少一份 required request 时，事实核查者在一个批量任务中逐 request 检查，记录稳定 check id、可定位来源、支持范围与完整覆盖。旧 URL 只能作线索，必须在本次运行重新定位核实。事实核查任务完整执行可为 pass，但任一候选的可见事实不是 supported，裁判仍淘汰该候选；不得靠减弱语气掩盖无证据，也不得让一个坏候选拖死其他候选。

### 6. 盲区检查与绝对裁判

同一个认知裁判先对整批候选做一次盲区检查：是否漏掉会改变结论的关键机制、反例、边界或事实冲突。发现关键遗漏时只输出定向退回问题，不自行追加候选；认知 Agent 补交后重新事实核查。没有关键遗漏时，裁判再按 rubric 对每条完整候选独立判定，不选“本批最好”，不按票数、覆盖面或候选成本放宽。三个实例全为 0 时，事实核查可 skipped，但裁判仍核对合法 0 报告与盲区并把绝对价值门结算为 pass；随后 writer 装配正文-only 页面，cold-reader 实际检查后返回 `not-applicable`，两项都不得 skipped。

历史正反例只按 `v3/standards/regression-suite.md` 的 B-* case 路由读取；作者、提名者和成文者不得读取回归包。

### 7. 观点锁定

主控把每个通过候选锁定为：原文落点、唯一判断、必要证据、读法改变、边界、禁止枝节。锁定后不得再选题、合并落选候选或引入新事实。

### 8. 单一成文

一个成文 Agent 接收全部锁定包，只负责把它们分别写成自然中文并放到对应正文附近。不得改题、加料、拼装落选素材、展开第二问题或补成小论文；篇幅只以说清这一项认知任务为准，说完即止。

读者可见文本不得出现锚点、候选、裁判、audit、金标等生产词，不得用宣告式收尾或中英混杂制造解释感。外文确需保留时首次给出中文含义；人物、概念和案例只保留理解判断所必需的信息。

### 9. 冷读

无生产上下文的冷读者逐条说明：它新增了什么、怎样改变附近原文的读法、能否一句话复述、是否还需读者二次整理。无法清楚回答任一项即退回；修订不得越过观点锁定，涉及新事实或新题目必须回到事实核查与裁判。

## 输出与停止

- 使用 `v3/skill/templates/book-chapter-page.md`；正文永远先于陪读单元。
- 只将完整通过执行链的单元写入读者页；0 个陪读单元是合法终态。
- `读完带走` 只能从已通过单元提炼；没有通过单元时省略，不用正文摘要或落选候选填补。
- source map、两次提名、归并、三批完整候选、事实核查、裁判内的盲区检查、观点锁定和冷读结果全部留在 audit。
- 任一步发现正文不可追溯、事实冲突会改变产品结论或需要改变强制数量规则时停止并交主控处理。
