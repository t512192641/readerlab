# 图书批注席引擎

## 目标

图书线不是写章节总结，而是在正文旁开一圈高手批注席。批注必须贴住原文，又带来原文之外的经验、学科、案例或跨书连接。

Phase 1 收档后的产品铁律：可见即精选。低于 `有用` 的批注不得出现在读者页；宁交内部活点，不交平庸批注。中档模型的主价值载体是章末延伸讲堂；页边批注是强档模型的增量。惊艳密度随模型档位、素材新鲜度和外部知识厚度变化，不作为硬保证。

## 输出形态

读者页固定保留“正文旁精选批注”和“章末延伸讲堂”两个槽位。批注槽位只出现存活批注，可以为空；讲堂体槽位每章必填。生产过程中的素材卡、候选池、自检记录和比较记录进入 audit，不进入读者页。

上页批注由两部分组成：

1. 锚点：1-4 条相关原文，优先保留语录之间的张力或矛盾。
2. 批注：80-150 字，一体成文，从锚点出发，场外走一趟，最后直接处理正文里的判断、动作或边界。

0 条存活时，不再把活点清单原样交给读者。活点先留在 audit，再转写为章末延伸讲堂；即使有批注存活，讲堂体也照常交付。

## 章末延伸讲堂

每章末把每个活点写成一段连贯讲课体，约 150-300 字。它不是列表，也不是素材索引，而是读者能直接读下去的一段讲解。

结构：

1. 从原文出发：先点出这一段原文真正卡在哪里。
2. 素材编织成叙述：把人、书、案例、概念串成一条说明线。每个人名带身份，每本书带一句它讲什么，概念随讲随解释。
3. 收回原文：最后直接谈作者这句话本身，让读者自然感到讲解回到了正文。禁止写“落回原文”“回到原文”“对应原文”这类宣告式收尾。

读者可见文本禁止：

- 列表、字段标签和问答表格。
- `素材线索`、`为什么值得批`、`活点`、`候选`、`裁判`、`金标`、`audit` 等生产词。
- 中英混杂。外文人名、书名、术语中文优先；确需保留原文时，括注最多一次。
- 把素材堆在一起但不串联。
- 让模板结构外露。
- 宣告式收尾，例如“落回原文”“回到原文”“对应原文”。收尾必须直接处理原文内容本身。
- 刻意书面腔。朗读测试必须像懂行的人当面讲；“而这恰恰意味着”这类连接词改成口语直连。
- 修辞堆叠。一段里修辞手法最多一处，优先保留解释和事实。

讲堂体和页边批注的关系：

- 中档模式：机械覆盖照做，批注席继续死刑制，读者页主要交付章末延伸讲堂。
- 强档模式：在讲堂体之外，若页边批注不输金标，可作为增量上页。

audit 中的活点清单最低字段：

1. 锚点原文。
2. 为什么值得批。
3. 素材线索：人、书、案例、概念或方法入口。

## 1. 选材 Pass

先识别活点，再选场外素材。不要先写批注。

活点包括：

- 原文中有明显张力、反常识、代价、边界、失败风险或方法入口。
- 原文只露出一个词、一句判断或一个动作，但背后有完整学科、案例、人物、书或方法。
- 原文和另一个章节、另一本书、一个真实案例之间存在可解释的对账关系。

每个锚点必须准备 5-7 路候选方向，方向要来自不同学科或付过学费的身份。每个锚点至少有一件非第一联想素材。非第一联想指不是本段关键词直接喊出的常见材料，而是能从远一点的位置照亮原文的事实、人物、书或方法。

每个候选场外素材必须先立素材卡。素材卡写入 audit，禁止进入读者页。

```text
anchor:
route_identity:
outside_material:
known_facts:
  - 具体事实 1
  - 具体事实 2
  - 具体事实 3（可选）
connection_to_anchor:
use_boundary:
source_confidence: high | medium | low
first_association: yes | no
decision: use | reject
```

素材卡规则：

- 写不出 2-3 个确实知道的具体事实，素材禁用。
- 连接必须具体说明它怎样照亮锚点，不能只写可类比、相似。
- 每个锚点至少保留一件 `first_association: no` 的素材进入候选池。
- 不确定的外部材料换掉，不能靠肯定语气补。

## 2. 成文 Pass

每个锚点生成 5-7 条候选批注。不同候选必须使用不同学科或身份出发，单条候选单独生成调用。候选只能使用通过素材卡的场外素材，不允许临场编新素材。

生成提示必须内嵌 `v3/skill/examples/book-annotation-examples.md` 中的：

- 2 条金标正例。
- 3 条典型反例。
- 每条反例对应的用户原话判词。

讲堂体生成提示必须直接粘入同一范例库中的：

- L-01 讲堂体金标原文，不得只引用编号。
- 至少一条典型反例及其用户原话判词，不得只写失败类型名称。
- 本章实际锚点与已通过素材卡的事实，不能拿金标的事实替代本章取材。

成文约束：

- 不写“本段说明”“提醒读者”“你应该”“读到这里可以”“这启示我们”。
- 不写开场铺垫、对仗修辞、格言式收尾。
- 外文术语必须配中文释义。
- 人名必须配身份短语。
- 概念必须随讲随用，不允许只报名字。
- 第一人称只在能交付实质知识时使用，不能用资历替代知识。

## 3. 自检 Pass

每一条读者可见产物都过二元清单，包括页边批注、章末延伸讲堂、活点转写、冰山页、沉淀候选说明和用户判定清单。命中任何一条，必须定点修复后复检；不能用整体感觉放行。

| 自检项 | 命中处理 |
| --- | --- |
| 外文无中文释义？ | 加一句短释义，或换中文可讲清的素材。 |
| 人名无身份短语？ | 加身份短语，例如“心理学家 Gary Klein”。 |
| 协议词或模板语泄漏进正文？ | 删除 `锚点`、`场外素材`、`环线结构`、`读者收益` 等生产词。 |
| 概念在工具箱已存在且未深化？ | 换新素材，或补一个此前没讲透的事实、案例、边界。 |
| 案例无出口？ | 补人名、书名、案例名、方法名或可追索入口。 |
| 与原文字面重复？ | 删除重复解释，改写为外部事实如何改变原文读法。 |
| 解释性推理超标？ | 删除读者自己能推出的道理，只留一个短机制句。 |
| 没有收回原文？ | 最后一句直接谈锚点动作、判断或边界，不写“落回原文”等宣告。 |
| 中英混杂？ | 外文改中文，必要原文只括注一次。 |
| 素材没有串联？ | 改成一条叙述线，删除并列堆料。 |
| 模板感外露？ | 删除字段标签和协议词，改成自然段。 |
| 协议词或宣告式收尾泄漏？ | 全文扫描 `落回原文`、`回到原文`、`对应原文`、`素材线索`、`为什么值得批`、`活点`、`候选`、`裁判`、`金标`、`audit`，命中即改。 |
| 措辞太刻意？ | 朗读一遍，删掉书面腔连接词；一段最多保留一处修辞。 |

## 4. 裁判 Pass

R6 使用死刑制，不再选“相对最好”的 60 分批注。

1. 先查即死项。命中即死项，修复后仍命中就淘汰。
2. 再做金标比较：页边批注候选逐条与批注金标正例比较，问题只有一个：这条是否不输金标？
3. 不能证明不输金标的候选淘汰；理由写入 audit。
4. 同一锚点可存活多条，也可存活 0 条。
5. 全批次存活 0 条时，不强行上批注；读者页的批注槽位保持为空，章末延伸讲堂照常交付。

讲堂体裁判也做金标与反例的成对比较：提示中必须逐字带入 L-01 和至少一条典型反例及其用户判词。它只判断这段是否更接近 L-01 而非反例；未通过时回到素材卡和成文 pass 重写，不能把素材清单直接交给读者。

## 禁止项

- 用高级词换皮原文。
- 把场内展开包装成批注。
- 用例子解释例子，但不交付新认识。
- 只报模型名、人名、书名，不解释其用法。
- 为了凑条数放出低于 `有用` 的内容。
- 把 audit、素材卡、暗桩、盲评或裁判术语写进读者页。
- 把活点清单的字段标签原样写给读者。
