# 图书批注席范例库

用途：供 `book-engine.md` 的成文 prompt 和成对比较裁判直接内嵌引用。这里不是完整校准日志，只保留能稳定塑形的金标和反例。

## 使用规则

- 生成 prompt 每次内嵌 2 条金标和 3 条反例。
- 裁判 prompt 比较候选时只问：哪条更像金标，哪条更接近反例。
- 用户原话判词优先级高于执行者自评。

## 金标正例

### G-01 土星五号 / 隐性知识

来源类型：用户确认形态正例。内容因重复曝光，不再用于后续惊艳判定。

批注：

这句别只读成“多读书多问人”。土星五号图纸还在，难的是焊接、容差、试车这些隐性知识断了；Harry Collins 说的 tacit knowledge，就是写不进手册的会。落回原文：书能开门，老手和现场才把手感补回来。

为什么是金标：

- 有真实对象：土星五号。
- 有人名和概念：Harry Collins，tacit knowledge。
- 概念随讲随解释：写不进手册的会。
- 最后落回原文，不停在航天史趣闻。

### G-02 事前验尸

来源类型：用户确认形态正例。内容因重复曝光，不再用于后续惊艳判定。

批注：

这句不是悲观，是 Gary Klein 的 pre-mortem：开工前先假设半年后失败，再倒推它怎么死。NASA 的 go/no-go 也干这事，把骄傲赶出房间。落回原文：胜券在握仍假设失败，是给自信装刹车。

为什么是金标：

- 人名有身份入口：Gary Klein 对应 pre-mortem 方法。
- 外文术语有中文解释：事前验尸。
- NASA go/no-go 是真实组织实践出口。
- 不是抽象劝告，而是把“假设失败”变成操作动作。

## 典型反例

### B-01 自我经验空转

来源：R3-A02。

原候选：

我们当年栽过一次：错不可怕，可怕的是错了还把会议纪要写得很坚定。真正贵的是自信延长了错误寿命。

用户判词：

废弃，我不是来听你吹牛逼的

失败类型：

- 第一人称没有交付新知识。
- 没有人、书、案例或方法出口。
- 只是把原文暗含道理换成有姿态的经验话。

### B-02 场内废话

来源：R3-A04。

原候选：

我见过太多“等规模上来就好了”的预算幻觉。把产量推到百万件后还贵，锅就不在规模，而在设计路线上。

用户判词：

废弃，说的都是废话

失败类型：

- 结论完全可由原文直接推出。
- 没有场外事实。
- 第一人称只增加姿态，不增加信息。

### B-03 黑话不落地

来源：R3-A10。

原候选：

我在交通项目里见过这种兴奋：几何上赢了，系统上又输回去。路变多以后，人也会重新选择开车。

用户判词：

平庸。啥叫几何上赢了，系统上又输回去？说点人话呢？

失败类型：

- 抽象短语没有翻译成人话。
- 外部经验没有给出可追索案例。
- 句子像写作姿态，不像懂行朋友随口讲。

## 可复用失败类型索引

| 失败类型 | 触发信号 | 修复动作 |
| --- | --- | --- |
| 自我经验空转 | “我见过”“我们当年”之后没有人、书、案例、方法 | 删除第一人称，换成具体外部素材 |
| 场内废话 | 去掉批注后原文意思没有任何损失 | 回到选材 pass，重找场外素材 |
| 黑话不落地 | 有漂亮短语，但普通读者要追问“啥意思” | 改成具体事实或例子 |
| 概念清单 | 一串术语，缺少展开 | 只留一个概念，随讲随解释 |
| 出口不足 | 没有人名、书名、案例名或方法名 | 补可追索出口，补不上就弃用 |
