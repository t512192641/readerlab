# 只保留特种部队

当前位置：《埃隆之书》·“只保留特种部队”完整小节

创办太空探索技术公司时，我倾尽全力组建专业团队。为寻找优秀火箭总工程师竭尽全力，但顶尖人才不愿加盟，平庸之辈又毫无价值。最终我亲自担任了火箭总工程师。若能找到更合适人选，或许我们的失败次数会少于三次。〔原注 268〕

最聪明、最有干劲的人才流向何处，何处便是赢家。〔原注 269〕

我对初创阶段企业秉持'特种部队'式管理哲学。最低达标标准是卓越。这恰是企业获得成功必须培育的文化内核。〔原注 270〕

问：打造顶尖团队和产品是否仅取决于资金充裕？

并非资金充裕就能高效投入研发，实际运作远非如此简单。若存在量产卓越工程师的工厂，此说方成立。可惜这样的工厂并不存在。寻觅顶尖人才、融入组织体系并实现高效运作，每一步都极具挑战。资金从来不是核心制约因素。

卓越人才本就稀缺难寻，工程师群体尤甚。 企业竞争力的本质，终将归结于顶尖人才的质量与驱动力。唯有人才云集的团队方能决胜。〔原注 271〕〔原注 272〕

根本瓶颈在于卓越工程师的稀缺性——这类人才本就凤毛麟角。〔原注 273〕

强烈的目标感将吸引全球顶尖人才。如果工作令人愉悦、薪酬回报丰厚，而且产品能改变世界——这便是极其强大的激励组合。〔原注 274〕

我曾多次在招聘决策中重视智力高于品性，现在想来实属失误。我已尝试做出相应调整。人品是否正直至关重要。〔原注 275〕

评估品性的一种方法是观察其朋友及交往对象的品性。虽然人们可以伪装自己的品性，但其朋友和交往对象不会伪装。通过交往对象可判断其人品，某种程度上通过其敌对者亦可判断。若遭恶人憎恨，或许说明你正行正确之事。〔原注 276〕

招聘时需寻觅心态端正者，技能可以后天培养。改变心态无异于实施大脑移植。

> **AI 陪读**
>
> 这里的“心态端正”不只是泛泛说人品好，也可以落到可观察的纪律上。美国海军核动力体系提供了一个高风险工程里的对照：Rickover 会亲自面试候选人，用高压、非常规提问观察他们在压力下是否镇定、是否愿意接受严格标准；后续运行又依靠工程化程序、密切监督、团队备份、审查和反馈机制。这样看，作者从智力转向品性，是因为聪明本身不够，关键是这个人能不能在压力和规则面前维护可靠运行。
