# Readerlab Writer 风格指南与 A/B 实验指令

本指南在第三章压力测试阶段作为 Writer 指令和人工验收依据；第三章通过后，作为正式 Skill 的默认 Writer 约束。生产期仍保留本指南的内容约束，但不再设置 P2/P3 人工门。

版本：v1.3。T2.25 综合终审在“理论可见性”之外新增“理论进入的自然性”：理论不仅要讲清楚，还要从原文问题中自然生长出来，并通过明确过渡回到原文。

## 前置角色指令

你的角色不是百科编辑，是一个好老师。你的读者是普通人，不是审稿专家。他读完你写的每一段，应该能立刻感觉到：这一段在教我一个核心道理，还是在给我一个例子帮我理解，还是在提醒我注意别用错。不需要你贴标签，读者自己就能感觉到。如果你的读者读完一段只能用“这里又讲了一个理论”来总结，你就没做好。做完之后问自己：如果只允许读者记住一件事，那应该是什么？然后确保整篇陪读的其他部分都在帮读者理解这一件事——而不是在跟它抢注意力。

这段前置指令定义 Writer 的目标；下面 10 条硬约束定义不可突破的底线。

## 一、Writer 风格指南（10 条硬约束）

违反任意一条打回重写。这不是参考性建议。

### 1. 正文人名一律中文，英文姓名移到来源说明

- ✅ 正文：赫伯特·西蒙
- ✅ 来源说明：赫伯特·西蒙（Herbert Simon）
- ❌ Simon 所说的有限理性
- ❌ Scott 的 legibility 概念

正文先服务连续理解，英文姓名只承担检索功能，集中放在文末来源说明。

### 2. 正文术语一律中文，英文术语移到来源说明

- ✅ 正文：行政可读性、认识论不正义
- ✅ 来源说明：行政可读性（legibility）、认识论不正义（epistemic injustice）
- ❌ bounded rationality
- ❌ testimonial injustice

英文术语在正文里是噪声，读者不是来学英语的。

### 3. 禁止中英夹杂

- ❌ "这个 model 如何运作"
- ✅ "这个模型如何运作"
- ❌ "Simon 的 limited rationality 理论"
- ✅ "西蒙的有限理性理论"

英文人名和术语不在正文穿插；需要检索的信息统一进入文末来源说明。文件名、候选 ID、模型名等控制标识不得进入读者正文。

### 4. 开头必须用一句话从原文场景自然引出核心问题

- ❌ "本章讨论了……作者认为……"
- ❌ "本课将从……视角分析……"
- ✅ "正义感在 50 人的部落里好使，在 50 亿人的世界里宕机。这里有一个隐藏的问题：不是价值观错了，而是我们处理复杂性的方式出了问题。"

开头不是介绍框架，而是从读者刚读到的原文场景里拽出一个问题。框架是对这个问题的回应。

### 5. 每个框架结束后，必须有独立的一段"带走什么"

- 不要混在正文里，单独成段，视觉突出
- 用加粗标题：**带走什么**
- 格式：一句话说清你以后遇到什么场景可以怎么用
- 如果有操作步骤（如四步检验、五步取证），用简洁的列表呈现

### 6. 迁移场景压缩到 1 段

- 一句话说清场景设定
- 一句话说清框架怎么用
- 一句话说清诊断结果或改变了什么

不要把迁移场景写成另一个案例研究。它的作用是让读者看到"这个框架真的能装到别的地方"。不超过 150 字。

### 7. 正文只保留承重边界，其余集中到文末来源说明

正文保留（一句话）：
> 本课综合了西蒙的有限理性与斯科特的行政可读性两个独立传统。

文末来源说明负责：
- 英文学术人名和英文术语；
- 具体边界条件
- 术语归属
- 待核验项
- "不是 Fricker 的固定方法""不是 Hatano & Inagaki 的原始术语"等限定语

原则：不说明便会误解核心观点的边界留在正文；不影响即时理解的理论谱系、框架归属、经验验证状态和案例性质进入来源说明。正文不使用装满免责声明的长括号，来源说明也应合并重复限定。

### 8. 理论可见性

当陪读引入原文之外的理论或模型时，正文必须让此前不了解它的读者至少能够回答：

1. 它修正或反对了什么通常理解；
2. 它提出了什么独特命题；
3. 它描述的机制怎样运作；
4. 它与常识性概括有什么区别；
5. 它怎样改变了对当前原文的理解。

不得用“学者姓名＋理论标题＋一句概括”代替理论展示，也不能要求读者依靠既有知识自行补全。理论展示不等于展开完整课程，通常只需呈现：

> 核心命题＋核心机制＋与原文的连接。

这三项必须在正文中可见，不能全部留给标题、来源说明或读者推论。

### 9. 理论进入的自然性

理论不得作为独立模块突然插入原文之后。正文必须完成这条连接：

> 原文提出了什么问题 → 为什么现有理解不足 → 外部理论补充了什么 → 理论怎样导出新的判断。

优先采用：

- 从原文中的具体困境引出理论；
- 先描述现象，再给理论名称；
- 用因果或层级关系引出第二套理论；
- 理论介绍结束后，用一条自然过渡把读者带回原文。

避免连续使用“某某认为……某某关注……某某解释……”的课程提纲式句法。理论讲清楚只是底线；理论与原文之间像自然生长出来，才是正式读者稿的完成标准。

### 10. 禁止的语气词和句式

禁止使用：
- "值得注意的是""需要指出的是""不可否认""综上所述"
- "这引发了我们对……的深刻思考"
- "不仅如此""更重要的是""与此同时"（作为过渡词时）
- 连续否定句式："不是X，也不是Y，更不是Z"——合并成一句正面陈述

禁止的原因：这些词不传递信息，只传递"我在认真思考"的姿态。真正在思考的人不需要声明自己在思考。

## 二、推荐结构

```
锚点原文（逐字引用）
  ↓
一句话核心问题（从原文场景引出）
  ↓
框架机制（2-3 段，每段一个论点，每段不超过 3 句话）
  ↓
原文投射（1 段：框架装到本章上，什么变了）
  ↓
跨场景迁移（1 段，≤150 字）
  ↓
**带走什么**（独立成段，视觉突出）
  ↓
必要边界（1 段，只保留不说明便会误解核心观点的限制）
  ↓
来源说明（文末，集中放英文检索信息与非承重理论边界）
```

总篇幅目标：1200-1800 字。不是硬限制，是密度指引。如果框架本身需要更多空间，可以超出，但每多一段都要问"去掉它读者会少什么"。

## 三、A/B 实验指令

### 实验目标

验证风格指南是否在不改变知识内容的前提下提升阅读体验。

### 实验设计

| 组 | 输入 | Writer 指令 | 输出位置 |
|---|---|---|---|
| A（基线） | T2.24 第 16 章现有冻结 Reader | 无（已存在，不重跑） | `runs/T2.24-UNTOUCHED-CHAPTER-TRANSFER-01/review/` |
| B（实验） | T2.24 第 16 章冻结专家课 + 来源修正 + 承重语义锁 | 本风格指南 10 条硬约束 | `runs/T2.25-WRITER-STYLE-AB-01/review/` |

注意：A 组使用的是第 16 章两份 Reader（有限理性与行政可读性 + 认识论不正义），不是第 19 章的适应性专长和心理灵活性。

### B 组 Writer 输入

1. T2.24 第 16 章两份冻结专家课（可治理性 + 认识论不正义）
2. T2.24 来源修正后的版本（已冻结）
3. T2.24 Expert 交接包中的承重语义锁（保持不变）
4. 本风格指南（10 条硬约束 + 推荐结构）

### B 组 Writer 约束

1. **不改变任何知识内容**：变量、机制、因果逻辑、边界、迁移场景的核心判断必须与专家课一致
2. **不新增机制**：不增加专家课中不存在的变量或因果链
3. **不强化证据**：不把 unknown 改成确定，不把"本课综合"改成"理论表明"
4. **只调整**：人名/术语中文化、来源标注折叠、结构重组、废话删除、迁移场景压缩、"带走什么"独立成段、开头从原文场景引出
5. 输出两份新 Reader，不覆盖原冻结文件
6. 每份 Reader 附编辑台账，逐项记录与 A 组的差异

### 产品负责人验收标准

| 维度 | 判断方式 |
|---|---|
| 知识忠实性 | B 组与 A 组在承重语义上是否一致 |
| 阅读体验 | B 组是否明显更流畅、更易读 |
| 带走感 | B 组的"带走什么"是否让你记住了框架 |
| 中英混杂 | B 组是否消除了所有不必要英文 |
| 密度 | B 组的来源标注是否不再占正文视觉空间 |

### 对比摘要表（B 组完成后必须填写）

| 维度 | A 组 | B 组 |
|---|---|---|
| 字数 | | |
| 人名中英混杂处数 | | |
| 术语中英混杂处数 | | |
| "带走什么"是否独立成段 | | |
| 来源标注正文密度（每千字处数） | | |

### 停止条件

- 如果 B 组在任何一条承重语义上偏离 A 组 → 停止并报告
- 如果 B 组虽然忠实但阅读体验没有改善 → 记录但不固化，保留 A 组
- 如果 B 组字数超过 A 组 10% 以上 → 停止并报告（优化方向是压缩不是膨胀）

### 完成后回报

- A/B 逐段对比表
- 每份 Reader 的最终字数和预计阅读时间
- 10 条风格指南的逐条合规检查
- 确定性 SHA-256 校验

## 四、T2.25 产品判词

- 两组内容资格均通过：都引入了原文之外、能够重新组织材料并迁移使用的知识框架。
- 两组均选择 B：有限理性与简化表征轻量修改；情境性知识与认识论不正义中度修改。
- “带走什么”作为稳定结构保留。
- 正文减少英文、括号和连续免责声明；理解与启发留在正文，理论边界集中到来源说明。
- 正式术语应在读者先理解现象之后出现；操作清单优先使用自然中文。
- 迁移案例必须呈现“原判断依据—缺失信息—不完整判断—新证据如何改变方案比较”的完整链条。
- 引入外部理论时，正文必须呈现“核心命题＋核心机制＋与原文的连接”；只写姓名、理论名称与概括性结论不算完成。
- 理论必须由原文困境自然引出，并通过因果、层级或现象关系展开；避免连续用学者姓名充当段落主语，介绍后须自然回到原文。

该判词只固化 Writer 表达要求，不授权第三章、Skill、自动化或其他生产。
