# T2.23 最小差分门

date-frozen: 2026-07-22
visibility: CONTROL_ONLY

本门在任何 T2.23 生产文件出现前冻结。Expert、Writer 均不得读取。

## 1. Expert v02 允许差分

去除紧邻修正句的 `<!-- 来源审核修正 ... -->` 标记后，两份 v02 专家课必须分别等于 v01 加以下语义替换，除此之外零差分：

1. A4：把泛化主体“常规专家容易把这种信号视为噪声，继续更用力地执行旧程序”收窄为“高度程序化的做法可能过度套用旧分类”。后半句“适应性专家……”不得借机改写。
2. A7：在高风险安全、协作与可回退要求前明确“作为高风险实践的外加治理要求”，其余边界不变。
3. #5：把“承诺行动就是……”收窄为“在本课中，承诺行动可以被落实为……”，其余例子、价值／目标关系不变。
4. #6：把“这三组动作形成一个循环”改为“可以把这三组动作理解为相互支持的关系”，其后的说明性关系链不变。

若 Agent 认为任何一项不能只靠上述措辞完成，必须停在该项并报告，不能扩写。

## 2. Writer v02 允许差分

- 先检查四项在 v01 读者稿中是否存在；不存在则记录 `NO_CHANGE_REQUIRED`。
- 只允许把实际存在的对应表述跟随到 Expert v02 的归属强度。
- 适应性专长“也不保证擅长一个领域的人能无成本迁移到任何领域”若已存在，记录 `ALREADY_PRESENT`，不得重复；若不存在，才允许补回该原句。
- 锚点必须逐字不变，正文不得重排、润色或删增其他字句。

预计但不预设的有效 Reader 差分是：A4 可能无需改；A7 一处前缀；#5 一处归属收窄；#6 一处归属调整；跨领域边界可能已存在。最终以实际文件证据为准。

## 3. 装配门

- 两份陪读分别插入对应原文段落之后，不合并、不另写过渡评论。
- T2.21 读者稿开头的锚点引文属于资格测试定位元数据；装配时由完整原文中的同一段承担锚点，因此不在 callout 内重复。标题进入 callout 标题，剩余知识正文逐字取自 v02 Reader。此容器转换不改 v02 Reader 文件。
- 移除两个新增 callout 后，章节正文必须与冻结完整原文逐字一致。
- 两个 callout 的知识正文还原后必须分别等于 v02 Reader 去掉开头锚点引文与一级标题后的正文。

## 4. 审阅门

端到端审阅稿必须包含：完整嵌入样张；两个锚点位置说明；四项 Expert 修正逐字前后对比；四项 Reader 跟随状态与跨领域边界检查；v01→v02 Reader 统一 diff；原文、两份陪读和整体的汉字数与统一口径阅读时长估算。
