# T2.21 Writer 资格判定门

date-frozen: 2026-07-22
visibility: CONTROL_AND_PRODUCT_OWNER_ONLY

本门在任何 Writer 交接包和读者稿产生之前冻结。Expert 与 Writer 均不得读取。两个对象独立判定；一份稿不能替另一份补偿。

## 1. 忠实性

- 读者稿的每项事实、知识身份、区分、关系、过程、因果、边界、结论和迁移判断，都能回指冻结专家课。
- Writer 没有新增、强化或悄悄修正专家课中不存在或仍为 `unknown` 的内容。
- 原有张力、限定条件和不确定性没有被改成更顺口但更绝对的说法。

出现任何承重语义新增或改变，即触发该对象 Writer 资格失败；文字是否漂亮不能补偿。

## 2. 承重知识保留

读者稿至少仍能让普通成年读者跟随：核心问题、知识对象自身的组织、完整但可压缩的推理、必须讲懂的概念、原文案例的实质作用、至少一个可迁移判断和关键边界。允许删除低收益支线、重复、后台台账和不影响理解的例证；不得只留下标题、结论、口号或操作清单。

## 3. 编辑增益

- 相比专家课，顺序、段落、节奏、术语进入方式和阅读负担有可感知改善。
- 读者无需先懂该学科，也不必在同一段承受过多陌生概念。
- “几分钟可读”是体验目标，不设固定字数；更短不自动更好。
- 若只是复制、轻微润色或机械删短，记为编辑价值未证明，而不是自动通过。

## 4. 原文锚点

- 稿首明确呈现 Expert 交接包提供的逐字原文锚点，不擅改字句，不另选锚点。
- 锚点必须是课程进入原文的真实入口；评论的认知范围不被锚点句局部锁死。
- Writer 不读取完整原文。若交接包不足以安全完成编辑，应停止并标 `unknown`，不得自行补原文。

## 5. 可审计性

- 编辑台账逐项说明保留、删除、重排、术语改写和可能的语义风险。
- 读者稿每个承重段落能回指专家课的具体章节或原句。
- 交接包中的语义锁均来自专家课并能回指；它只传递锚点与冻结约束，不新增一堂课。

## 产品判词格式

每个对象分别给出：

1. 实验按卡完成：通过／未通过；
2. 忠实性：通过／未通过；
3. 承重知识保留：通过／未通过；
4. 编辑增益：通过／未通过；
5. 锚点与可审计性：通过／未通过；
6. Writer 是否取得该对象的编辑资格：是／否；
7. 该读者稿是否值得进入后续合并或原文融合实验：是／否／`unknown`。

Writer 资格是局部证据，不自动外推到其他知识对象、章节、长度或合并任务。
