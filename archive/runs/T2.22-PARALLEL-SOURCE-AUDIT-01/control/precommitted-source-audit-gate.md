# T2.22 轻量来源审核判定门

date-frozen: 2026-07-22
visibility: CONTROL_ONLY

本门在来源审核启动前冻结。来源审核只判断两份已通过专家课的承重知识是否有可追溯依据，不承担 Writer、产品价值或改稿责任。

## 有效审核必须做到

1. 只抽取会影响整堂课成立的对象身份、核心区分／过程／关系、重要机制和关键边界；不把每个例子与措辞都扩成文献综述。
2. 每项承重主张分别标为 `SUPPORTED`、`CORRECTION_NEEDED` 或 `UNKNOWN`，并说明证据实际支持到哪一层。
3. 优先使用知识对象提出者、原始论文／章节、同行评审研究或负责该模型的权威机构材料；搜索摘要、聚合页和二手解释只能帮助发现来源，不能单独作为定论。
4. 清楚区分理论原有结构、后续常见组织、专家综合、说明性案例和应用推论，不因它们合理就冒充原理论原文。
5. 若需纠正，只给最小语义修正建议及影响范围；不得直接编辑专家课或 Writer 稿。
6. 链接、标题、作者与所支持主张可核对；遇到付费墙或正文不可得，明确降低结论强度。

## 失效信号

- 只证明术语“存在”，没有核对课程中的承重结构。
- 用百科、博客、搜索摘要或模型记忆替代可追溯来源。
- 把没有来源的专家综合包装为理论原说。
- 为追求全面而失控扩张，或替产品负责人评价课程好不好。

来源审核与 Writer 资格测试并行。其结论不阻塞 Writer 是否忠实的实验判词，但任何 `CORRECTION_NEEDED` 或承重 `UNKNOWN` 必须在未来真实产品使用前处理。
