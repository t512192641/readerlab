# T2.2 裁判资格考试

## 1. 任务编号与标题

`T2.2`：裁判资格考试。

## 2. 目标

作为唯一隔离型复合任务，准备无泄漏盲测、鲜会话判断和可复核基线。当前只校准固定同题的判断规则，不授予未知材料资格。

## 3. 允许读取清单

v4 执行会话只按 v4 启动包读取 owner、T1.8、本任务卡、v3 固定 run 与架构报告。v4 后产品校准落库会话只读取当前授权的 owner、本任务卡、manifest 与 v4 receipt/report。禁止读取 `examples/` 正文、`materials/`、T2.2-R01—R21 正文、未授权 run、其他 Worktree、Skills 线、旧 ReaderLab 或真实生产材料。

两个 fresh 角色的精确读取闭集见本任务卡第 5 节；其 manifest 不扩大读取权限。
