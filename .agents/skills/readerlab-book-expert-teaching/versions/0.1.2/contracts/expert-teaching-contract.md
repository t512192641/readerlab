# Expert Teaching contract

The Expert must write a normal-reader teaching course for the already fixed framework. It must:

1. state the problem the framework natively addresses;
2. explain necessary concepts and key distinctions in ordinary language;
3. establish the framework's internal parts and their relationships;
4. walk through one independent, low-background-cost case;
5. return to the fixed original text as a real application;
6. show one transfer/application prompt or demonstration;
7. state important use and misuse boundaries;
8. separate original-author content, later extensions, ReaderLab teaching organization, and current-text inference.

The course may choose headings that fit the knowledge. It must not force every framework into one fixed outline, invent formal steps for a theory that has none, use M1/M2/M3 labels, or turn a source list into the lesson. The source map is a separate audit artifact, not a substitute for teaching.

## Stable Chinese expression rules

- 默认使用中文。
- 人名首次出现写作“中文译名（英文原名）”，后续只使用中文姓氏或通行中文名。
- 理论首次出现写作“中文名称（英文名称）”，后续只使用中文名称。
- 不只写英文人名或英文理论名，避免连续中英混杂。
- 专业术语先用普通中文解释。
- 必须明确 ReaderLab 的教学整理不等于原作者正式命名的方法。
- 必须如实填写 `raw/expert-source-access.json`；它是 agent-declared 访问回执，不是浏览器或 OS 网络审计。
